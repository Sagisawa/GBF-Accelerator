【はじめに：セキュリティ警告・未署名アプリの起動許可について】
-----------------------------------------------------------------
GBF-Accelerator は、オープンソースの高性能ローカル静的キャッシュ＆
透過プロキシツールです。完全無料・オープンソースで開発されており、
有償のコード署名証明書を取得していないため、初回起動時に OS の
セキュリティ機能により警告が表示される場合があります：

• Windows 10/11（Microsoft Defender SmartScreen による保護）：
  初回起動時に「Windows によって PC が保護されました」または
  「SmartScreen で認識されないアプリの起動を防止しました」と表示された場合：
  1. ダイアログ内の「詳細情報」をクリックします。
  2. 右下に表示される「実行」をクリックすると正常に起動します。
  （セキュリティソフトに検知された場合は、除外・信頼リストに追加してください）。

• macOS（Gatekeeper による警告）：
  初回起動時に「開発元を検証できないため開けません」と表示された場合：
  1. Finder で GBF_Accelerator.app を右クリック（または Control キーを押しながらクリック）し、
     「開く」を選択します。
  2. または「ターミナル」を開き、以下のコマンドを実行して隔離属性を解除します：
     xattr -cr /Applications/GBF_Accelerator.app

【クイックスタート：標準 4 ステップ利用手順】
=================================================================

ステップ 1：上流プロキシの準備
-----------------------------------------------------------------
1. お使いのプロキシ／VPN クライアント（Clash、v2rayN、Surge 等）が
   起動しており、正常にインターネット通信ができる状態であることを確認します。
2. GBF-Accelerator は「ローカルキャッシュ中継ツール」として動作します。
   起動時に以下の一般的な上流プロキシポートを自動検出します：
   • Clash Verge：7897
   • Clash：7890
   • v2rayN：10809
   • 島風GO：8099
   • ACGPower：8123
   コンソール画面の「上流プロキシ」ドロップダウンから自由に切り替え可能です。
3. 日本国内からの直接接続など、高速な直接回線環境をお持ちの場合や、
   商用ゲーム加速ツールと併用する場合は、コンソールで【ダイレクトモード】
   にチェックを入れることで上流プロキシをバイパスできます。

ステップ 2：プログラムの起動とルート証明書（CA）のインストール【初回必須】
-----------------------------------------------------------------
ゲームの静的アセット（画像・音声・演出）は Akamai CDN を通じて HTTPS で
配信されます。本ツールがローカルで復号・キャッシュ配信を行うために、
お使いの端末でローカル生成された専用ルート証明書（Root CA）を信頼する必要があります。

1. GBF_Accelerator.exe（Windows）または GBF_Accelerator.app（macOS）を起動します。
2. Web 管理コンソールが自動的に開きます（既定 URL: http://127.0.0.1:8125）。
   • 画面右上の【🌐 言語】メニューから、いつでも「日本語」「English」「简体中文」
     を切り替え可能です。
3. ルート証明書が未インストールの場合は、コンソール上に案内モーダルが表示されます。
4. インストール方法（いずれかを選択）：
   • 方法 A（推奨・ワンクリック）：コンソール上部の「ルート証明書をインストール」をクリック。
     OS の確認画面が出たら「はい」を選択します。
   • 方法 B：フォルダ内の install_ca.bat（Windows）または ./install_ca.sh（macOS）を実行。

【重要】証明書インストール後は、必ずブラウザを完全に再起動してください！
現在ブラウザ（Chrome、Edge 等）を開いている場合は、全ウィンドウを一度完全に閉じて
再起動してください。
Chromium 系ブラウザは起動中に SSL/TLS ハンドシェイク状態をキャッシュしているため、完全再起動
を行わないと証明書エラー（NET::ERR_CERT_AUTHORITY_INVALID）や画面が真っ白になる現象が発生します。

ステップ 3：ブラウザのプロキシ振り分け設定（SwitchyOmega / ZeroOmega）
-----------------------------------------------------------------
グラブル（GBF）のゲーム通信とアセットのみを本ツール経由にし、その他の日常的な
Web ブラウジングに影響を与えないよう設定します。

• PAC 自動振り分け（推奨）：
  1. Chrome / Edge に「ZeroOmega」または「SwitchyOmega」拡張機能を導入します。
  2. 拡張機能のオプションを開き、「新規プロファイル（New Profile）」->「PAC プロファイル」を選択。
  3. PAC の URL に次を入力：http://127.0.0.1:8124/proxy.pac
  4. 「今すぐ更新」をクリックし、左メニューの「設定を適用」をクリック。
  5. ブラウザツールバーのアイコンをクリックし、作成した PAC プロファイルを選択します。

• 代替設定（Windows システム PAC）：
  コンソール画面で「Windows システム PAC プロキシを自動構成」にチェックを入れます。
  （※ SwitchyOmega を併用している場合は、SwitchyOmega 側を［システムプロキシ］にするか
   一時的に無効化してください）。

ステップ 4：ゲーム開始とキャッシュ効果の確認
-----------------------------------------------------------------
1. ブラウザで公式ゲーム URL を開きます：
   https://game.granbluefantasy.jp
   （※ SkyLeap 専用の gbf.game.mbga.jp は認証・リダイレクト専用のため使用しないでください）。
2. キャッシュヒットの仕組み（ブラウザ内部メモリ vs プロキシローカルキャッシュ）：
   • 初回アクセス時：CDN からアセットを新規ダウンロードし、SSD ディスクキャッシュに保存します。
   • 直後の再アクセス：現代のブラウザ（Chrome / Edge 等）は内部メモリ（Memory Cache）
     から直接読み込むため、ローカルプロキシへ通信自体が送られません。
   • しばらくプレイした後／ブラウザ再起動後：ブラウザ内メモリが循環・破棄された後の通信は、
     本ツールの超高速ローカルキャッシュ（RAM 0ms / SSD 1〜3ms）に 100% ヒットし、
     コンソール上部の「ローカルキャッシュヒット」数が急激に増加します。

【便利な機能と管理】
=================================================================

1. 予備プロキシと自動フェイルオーバー：
   メインの上流プロキシでタイムアウトや切断が起きた際に、自動で予備プロキシ（またはダイレクト）
   へ切り替えるフェイルオーバー機能を備えています（コンソールの「上流プロキシ」設定）。

2. アプリ内アップデート確認：
   コンソールの「更新確認」から GitHub Releases の最新版をチェックできます。
   公式 SHA-256 チェックサムの照合を経て安全に適用されます。

3. キャッシュの安全スリム化：
   コンソールの「キャッシュ削除」機能により、ゲームの過去アップデートで不要になった
   旧バージョンのスクリプト残骸のみを安全に一括削除できます（キャラ立ち絵等は安全に保持）。

4. アンインストール・証明書の削除：
   使用を中止する場合は、コンソールから「ルート証明書をアンインストール」をクリックすることで、
   OS の証明書ストアから綺麗に削除されます。
