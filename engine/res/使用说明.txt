=================================================================
   GBF 加速器（GBF Accelerator）使用说明与全流程指引
=================================================================

【写在前面：开源软件未签名与安全拦截说明】
-----------------------------------------------------------------
本项目为开源本地静态资源缓存与透明代理工具，完全免费且代码开源。
由于未采购商业代码签名证书，部分操作系统首次运行时可能会弹出安全警告：

• Windows 10/11 用户（SmartScreen 拦截）：
  首次双击 GBF_Accelerator.exe 时，若弹出【Windows 已保护你的电脑】或
  【Microsoft Defender SmartScreen 阻止了无法识别的应用启动】弹窗：
  1. 点击弹窗上的【更多信息】（More info）；
  2. 点击右下角出现的【仍要运行】（Run anyway）即可正常启动。
  （若被第三方杀毒软件拦截，请点击“信任并放行”或添加至白名单）。

• macOS 用户（Gatekeeper 拦截）：
  首次打开 GBF_Accelerator.app 时，若提示“无法验证开发者”或“已损坏”：
  1. 在【访达】（Finder）中找到该应用，按住 Control 键并鼠标右键点击，选择【打开】；
  2. 或打开系统【终端】（Terminal）执行以下命令解除系统隔离：
     xattr -cr /Applications/GBF_Accelerator.app

【快速上手：标准 4 步全流程】
=================================================================

第 1 步：准备上游代理（前置网络）
-----------------------------------------------------------------
1. 确保你的代理软件（Clash Verge / Clash / v2rayN / Surge 等）已开启并正常翻墙联网。
2. 本加速器作为“本地中继与缓存加速中间件”，默认会自动探测本机的上游代理端口：
   • Clash Verge 常见为 7897
   • 原版 Clash 常见为 7890
   • v2rayN 常见为 10809
   • 岛风 GO 默认为 8099（开启后可自动适配并支持自签证书）
   • ACGPower 常见为 8123（开启后可自动适配并支持自签证书）
   若同时开启了多个代理，可在控制台的“上游代理”下拉框中自由切换。
3. （可选）如果你本地直连网络质量较好，或想配合商业加速器加速 GBF，可在软件界面勾选【直连模式】。（部分商业加速器的进程模式可能需要识别为 Chrome：Windows 可将程序改名为 `chrome.exe`；macOS 可打开 `GBF_Accelerator.app` →【显示包内容】→ `Contents/MacOS/`，将内部可执行文件改名为 `chrome`，并同步将 `Contents/Info.plist` 中的 `CFBundleExecutable` 修改为 `chrome`。）

第 2 步：启动本程序并安装 HTTPS 根证书（【必做】，只需首次操作一次）
-----------------------------------------------------------------
静态素材由 Akamai CDN 经由 HTTPS 传输，必须信任本机独立自签的根证书，否则浏览器会拦截素材并报错证书无效！

1. 启动本程序（Windows 双击 GBF_Accelerator.exe，macOS 打开 GBF_Accelerator.app）；
2. 程序启动后会自动打开 Web 管理控制台页面（默认地址 http://127.0.0.1:8125）；
3. 首次检测到根证书尚未受系统信任时，控制台会自动打开证书安装引导（每次启动最多提示一次）；
4. 证书安装方式（二选一即可）：
   • 方式 A（推荐，界面一键）：在控制台界面顶部点击【一键安装根证书】。Windows 会弹出系统原生证书安全确认，请确认安装；macOS 按系统提示完成钥匙串信任。
   • 方式 B（脚本安装）：直接双击运行本程序根目录下的【install_ca.bat】（macOS 用户运行 ./install_ca.sh），按提示确认。

【Windows 证书提示】
一键安装和一键注销都通过 Windows 证书存储接口执行，因此会保留系统原生安全确认。注销后再次安装时，也会正常重新出现安装确认。

【关键提醒：安装证书后务必完全重启一次浏览器！】
若当前你的浏览器（Chrome / Edge 等）正处于打开状态，在安装/信任证书后，请务必【完全关闭所有浏览器窗口并重新打开浏览器】！
原因：Chromium 内核浏览器的网络服务（Network Service）在运行中会缓存系统证书库与历史 TLS 握手状态。只有完全重启浏览器，浏览器才会重新载入受信任根证书库，从而杜绝打开游戏时报错“证书不受信任”或素材白屏问题！

第 3 步：配置浏览器分流（推荐使用 ZeroOmega / SwitchyOmega 插件）
-----------------------------------------------------------------
分流的目的是让“仅 GBF 游戏流量与素材”经过加速器，其他网页正常直连或走梯子，互不干扰。

• 推荐方式（最省心、永不漏 CDN 分片、免手动维护）：
  1. 在 Chrome / Edge 浏览器中安装 ZeroOmega 或 SwitchyOmega 扩展；
  2. 打开插件设置 -> 点击左侧【新建情景模式】 -> 选择【PAC 情景模式】；
  3. PAC 网址填入：http://127.0.0.1:8124/proxy.pac，点击【立即更新】后点击左侧【应用选项】；
  4. 点击浏览器右上角插件图标，直接切换为该 PAC 情景模式即可！

• 备用方式 1（免插件，Windows 系统 PAC）：
  在控制台主界面直接勾选【自动配置 Windows 系统 PAC 代理】。
  【注意】：如果你浏览器安装了 SwitchyOmega，必须将插件图标切换到【[系统代理]】档位或暂时禁用插件，否则浏览器插件会强行覆盖系统代理导致失效！

• 备用方式 2（Clash TUN 虚拟网卡模式共存方案）：
  若电脑开启了 Clash TUN 模式接管虚拟网卡，TUN 会抢占系统 PAC 路由。此时推荐在 SmartProxy 插件中配置专属分流：添加 127.0.0.1:8124 代理目标，并将以下 7 条域名指向该代理：
  - granbluefantasy.jp
  - granbluefantasy.com
  - mbga.jp
  - mobage.jp
  - *granbluefantasy.akamaized.net
  - *gbf.akamaized.net
  - *granbluefantasy-steam.akamaized.net（Steam版）

第 4 步：进入游戏与加速生效确认
-----------------------------------------------------------------
1. 在浏览器中直接输入并打开官方游戏地址：
   https://game.granbluefantasy.jp
   【特别提醒】：请勿使用 SkyLeap 的 gbf.game.mbga.jp 地址游玩，该域名主要用于手机账号鉴权与跳转，不包含任何游戏静态素材，无法触发本地缓存加速。
2. 如何确认加速已正常生效（技术原理与命中判定）：
   • 首次进入新场景或副本：由于本地尚无素材，需经由网络首次下载，加速器会自动将其持久化写入本地磁盘缓存；
   • 同一会话短时间内重复进入：现代浏览器（Chrome / Edge 等）首次下载后会将其优先驻留在浏览器的内存缓存（Memory Cache）中。此时浏览器直接由内存内部读取，不会向加速器发起外部网络请求，因此控制台暂不会计入命中；
   • 当游玩一段时间后、或重启浏览器、或第二天再次游玩时：浏览器内部内存缓存已释放，重新请求的静态素材将 100% 命中加速器的本地缓存（RAM 内存 0ms / SSD 磁盘 1~3ms 瞬时交付），此时控制台顶部的【本地缓存命中】数字会快速跳动增加；
   • 快速验证技巧：完全关闭并重新打开浏览器，再次进入曾打过的副本，观察控制台顶部的命中数字与网络监控，即可直观确认加速生效。

【可选功能：备用上游与自动故障转移】
=================================================================
当你的主上游代理存在偶发断连、连接拒绝或持续高延迟时，可以配置一个备用上游，让程序在满足条件时自动切换。

1. 在控制台的“上游代理”区域打开【启用备用上游自动切换】；
2. 填写【备用地址】：
   • HTTP / HTTPS：例如 http://127.0.0.1:7890
   • SOCKS5：例如 socks5://127.0.0.1:1080
   • 直连：填写 direct，主代理故障时改为本机直连；
3. 可调整三个参数：
   • 【上游响应阈值】：响应超过该毫秒数会计为延迟异常；
   • 【连续异常水线】：延迟异常累计达到设定次数后切换；
   • 【切回等待】：切换到备用上游后，等待指定时间再尝试恢复主上游；
4. 【冷却后自动尝试切回主上游】开启时，恢复探测成功会自动切回主上游；
5. 连接拒绝、连接超时等硬连接错误会直接触发切换，不需要等待连续异常次数；
6. 该功能默认关闭，且在【直连模式】下不可用。未开启时，程序仍按原来的单上游方式运行。

【可选功能：程序内下载更新】
=================================================================
控制台内置版本检查与更新功能，仅针对 GitHub Releases 的正式发布版本。

1. 打开控制台的【版本检查与更新】；
2. 程序会按当前系统自动筛选 Windows / macOS 对应的发布包；
3. 有新版本时可直接下载，界面显示实时进度；
4. 下载完成后会自动校验官方 SHA-256 以及安装包归档完整性；
5. 校验通过后可直接应用更新并自动重启程序；
6. 若该 Release 没有可验证的 SHA-256，则不会执行自动应用，可打开下载目录后手动更新；
7. Windows / macOS 用户使用该功能时，无需手动修改缓存目录或配置文件。

【移动端（手机 / iPad）局域网接入说明】
=================================================================
1. 确保手机与电脑连接在同一个 Wi-Fi 局域网下；
2. 在电脑端控制台开启【允许局域网连接】（需要放行 Windows 防火墙时，点击界面的一键防火墙适配）；
3. 手机浏览器访问控制台显示的局域网地址（例如 http://192.168.x.x:8124/），根据移动端向导页完成证书安装与 Wi-Fi 代理配置：
   • iOS 必做：下载描述文件安装后，必须前往【设置】->【通用】->【关于本机】-> 底部【证书信任设置】，打开“GBF Local Accelerator Root CA”的完全信任开关！
   • Wi-Fi 代理：选择【自动】，URL 填入 http://<电脑IP>:8124/proxy.pac。

【常见问题与技术说明】
=================================================================
1. 为什么抽卡、编队、战斗结算的延迟没有感觉明显变快？
   - 本加速器是【静态资源缓存加速器】，专门解决立绘、背景、技能动画、音频等 GBF 庞大静态素材加载卡顿、黑屏的问题。
   - 游戏的动态 API 请求（攻击、技能、抽卡、多人战）遵循业务语义绝对透明原则，端到端原样转发至上游代理，不干预、不伪造任何游戏数据，因此动态交互延迟完全取决于你的梯子节点网络质量。
2. 为什么短时间内打两次同一个副本，控制台的【本地缓存命中】数字没有立即增加？
   - 这是现代浏览器（Chrome / Edge 等）自带的 Memory Cache（内存缓存）机制所致：第一次下载素材后，浏览器自身会在标签页内存中保留副本；短时间内再次进入时，浏览器直接由内存瞬间交付（Network 抓包显示 from memory cache），根本不会向外部网络或本地代理发出任何请求。
   - 只有当你玩了一段时间后（浏览器内存缓存置换淘汰）、或是彻底重启了浏览器、或是第二天重新游玩时，浏览器重新向代理发起素材请求，才会全部命中加速器的本地高速缓存并快速跳动计数。
3. 缓存占用磁盘过多怎么办？
   - 控制台提供了【历史版本安全瘦身】功能，会自动清理已被游戏更新废弃的历史旧版本代码碎片，立绘与音频等高价值大素材 100% 完好保留。
4. 卸载或不再使用时如何清理证书？
   - 控制台支持【一键注销证书】，会通过系统证书存储接口彻底移除本机 Root CA；Windows 会显示系统原生确认。注销后再次安装同一证书时，会正常重新出现安装确认。
