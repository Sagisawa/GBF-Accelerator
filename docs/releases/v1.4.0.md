# GBF Accelerator v1.4.0

## 新增与改进

### 1. 岛风GO 专属兼容优化模式
- **智能探测与接入引导**：点击“自动探测”若识别到岛风GO（端口 8099），将弹窗提示一键启用【岛风GO 兼容优化模式】。
- **超时与拥塞放宽**：针对国内线路晚高峰跨海拥塞情况，将连接与读取超时由 15s/8s 放宽至 25s/12s，显著减少 504 Gateway Timeout 报错。
- **幂等 API 自动重试自愈**：针对 GET/HEAD 等安全幂等接口，若遇到上游代理网络波动或 504 网关超时，新增自动 1 次重试机制，大幅提升页面首刷与切图稳定性。
- **HTTPS 适配与防冲突提示**：适配岛风GO 自签根证书，界面以醒目红字提示关闭岛风GO远端缓存，彻底杜绝双重反代冲突。

### 2. GUI 界面扩容与高分屏适配
- **界面扩容拉长**：默认窗口尺寸扩容至 680x830，彻底解决高分屏（125%/150% DPI 缩放）下底部“性能与系统资源选项”以及操作工具栏截断显示不全的问题。
- **自适应居中与越界保护**：全组件装载后执行屏幕居中计算，加入防负坐标越界保护，确保在各类分辨率屏幕（1080P / 2K / 笔记本）均能完美居中显示。

### 3. 配置持久化与热重载
- `shimakaze_mode` 完整纳入 `config.json` 持久化，界面勾选即时生效并热重载上游 HTTP 连接池。
