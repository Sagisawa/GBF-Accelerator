# GBF Accelerator v1.7.0

GBF Accelerator v1.7.0 带来了全新的网络并发架构、图形化遥测面板以及多项实用缓存增强功能。

---

## 🌟 新增功能

### 1. 动态 API 与静态素材双通道物理隔离
- 引入双独立的 `httpx.AsyncClient` 客户端，将核心游戏 API 与静态素材下载彻底物理分流：
  - **API 专享通道 (`api_client`)**：专职处理 `/rest/`、`/socket/`、`/content/` 等游戏动态指令，独享专用连接池。
  - **静态素材通道 (`asset_client`)**：专职处理立绘、音频、脚本下载与后台预取队列。
- 即使后台正在并发预取上百个副本素材，游戏战斗、刷新与操作 API 也拥有独立畅通的专属链路，互不排队、互不干扰。

### 2. TCP 长连接池复用与协议专精加速
- **API 通道（HTTP/1.1 长连接复用）**：
  - 精准匹配游戏服务端协议，采用定制连接池（`max_connections=16, max_keepalive=4, keepalive_expiry=20s`）。
  - 连续操作与刷新时自动复用已建立的 TCP+TLS 加密链路，省去每次重复握手的时间开销，显著降低连续 API 请求的延迟。
- **静态素材通道（HTTP/2 多路复用）**：
  - 维持 HTTP/2 支持，连接池参数配置为 `max_connections=100, max_keepalive=40, keepalive_expiry=60s`，支持在单条链路上高并发拉取素材切片。

### 3. 白名单只读接口智能重连自愈
- 针对 `/socket/query`、`/content/index/`、`/rest/multiraid/start.json` 等已确认无副作用的只读 GET 接口，当遇到网络波动或空闲长连接断开时，代理会自动重建连接并重新请求一次，平滑消除偶发的断连报错。
- **操作安全保障**：所有 POST 请求及带状态变更的请求坚决不重试，杜绝重复提交与连击异常。

### 4. GUI 实时日志与连接状态监控窗口
- 主界面底部新增「📜 实时日志」按钮，点击即可呼出独立的深色监控窗口。
- **连接状态直观可见**：日志中明确标记 `, reused`（复用已有长连接）与 `, new`（新握手建连），连接池加速效果实时掌握。
- **快速检索与分类过滤**：支持关键词即时过滤，并提供「全部 / API / 缓存 / 预取 / 错误 / 证书 / 连接」快捷标签切换。
- **轻量零开销**：采用异步生产者-消费者队列与定长环形内存缓冲，界面渲染完全不占用代理转发性能。

### 5. 素材文件头格式校验与「一键体检缓存」
- 写入与读取缓存时全面引入 Magic Bytes 二进制文件头校验，自动拦截损坏的 0 字节文件与伪装成素材的 HTML 报错页面。
- 主界面新增「🩺 一键体检缓存」按钮，支持一键扫描并清理已有缓存中的损坏与截断文件，方便游戏后续重新拉取健康素材。

### 6. 跨版本/跨语言历史缓存平滑兜底
- 当遇到上游网络抖动或超时报错时，系统会自动检索本地已有的旧版本或异语版本安全资源（如图片、音频、样式及 CreateJS 动画切片），作为临时只读兜底响应，有效防止游戏因个别非关键素材加载失败而白屏或卡住。

### 7. CreateJS 角色动画切片与双生脚本智能预取
- 深度支持 CreateJS 动画依赖解析，自动提取角色与召唤石序列图（`/sp/cjs/`）。
- 支持根据模型 manifest 清单推导预取双生脚本，进入战斗时相关动画素材提前在后台就绪。
