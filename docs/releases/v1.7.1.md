# GBF Accelerator v1.7.1 发布说明 (Release Notes)

> **发布日期**：2026-09-16  
> **版本定位**：行为透明化、客户端体验与稳定性维护更新  
> **发布包**：GBF_Accelerator_v1.7.1_GUI.zip

---

## 🌟 版本概述

GBF-Accelerator v1.7.1 是 1.7 系列的重要维护与体验提升版本。本版本进一步收敛了代理自身的行为边界，提升与官方资源、动态 API 及历史缓存的兼容性；同时整合了自 1.7.0 以来的一系列客户端体验优化（内置更新下载、日志导出、托盘 0% CPU 占用等），并修复了托盘退出生命周期问题。

**本版本完整保留 1.7.0 的核心加速架构（RAM Cache、Disk Cache、API/素材物理双连接池、长连接复用），加速效果不减速、零缩水。**

---

## 🚀 主要更新内容

### 1. 🌐 透明代理与行为规范化
- **动态请求标准透传**：游戏动态 API、官方心跳（/ob/r）及报错请求恢复标准原样透传，不再由代理生成本地响应。
- **静态脚本原始内容交付**：静态 JavaScript 脚本保持逐字节原版交付，不再对前端代码进行额外修改。
- **响应标头精简**：移除发送给浏览器的内部调试 Header（如 X-Proxy-*），调试与耗时数据仍完整保留在本地 GUI 与实时日志窗口中。
- **后台预加载标头规范**：优化后台 Prefetch 标头与资源预热兼容性，采用合规标准浏览器 UA，仅携带必要协议信息。

### 2. ⚡ 客户端交互与体验升级
- **内置一键下载更新**：检测到新版本后，支持在客户端内直接发起下载，提供实时百分比进度条，下载完成后可一键在文件资源管理器中定位安装包。
- **实时日志查看器增强**：
  - 优化日志着色排版与分类标签过滤；
  - 增加便捷快捷键操作（如快速聚焦检索、快捷复制行）；
  - 支持将当前过滤后的网络与转发日志一键导出保存为本地文件。

### 3. 🔋 功耗与性能深度优化
- **托盘最小化 0.0% CPU 占用**：主窗口最小化至系统托盘后，自动挂起 GUI 界面的定时刷新循环，后台挂机期间 CPU 占用降至绝对的 0.0%。
- **精准 RAM 内存预热重构**：重构启动时的静态资源预热逻辑，优先扫描并装载当前活跃版本及高频核心 UI 资源，提升冷启动效率，避免无效内存占用。

### 4. 📦 缓存兼容性与自愈
- **旧版缓存无缝兼容**：推荐 1.7.0 用户直接覆盖升级，现有 cache 目录与 config.json 配置 100% 兼容，**无需重新下载素材，无需清空缓存**。
- **历史修改文件自动恢复**：检测到包含旧版修改特征的历史 JS 文件时，自动隔离备份至 .quarantine 并重新拉取官方原版，不影响正常缓存复用。
- **保持缓存自愈能力**：继续保留 Magic Bytes 文件头完整性校验与损坏缓存“一键体检自愈”能力。

### 5. 🛠️ 稳定性与问题修复
- **修复托盘彻底退出生命周期**：完善 Windows 托盘菜单“彻底退出”控制流程，确保托盘图标立即注销、系统 PAC 代理复原、GUI 窗口销毁与进程彻底退出。
- **网关超时可观测性增强**：详细区分记录上游超时类型（ConnectTimeout 连接超时 / ReadTimeout 读取超时）及具体消耗毫秒。
- **PAC 规则精简**：移除对非 GBF 相关统计域名的额外接管，专注于官方游戏主站、CDN、Steam 专用 CDN 与 Mobage 授权全链路。
- **自动化测试扩充**：集成测试用例扩充至 54 项并全部通过，全面覆盖透传保真、资源一致性与托盘生命周期。

## ⚡ 性能说明

**核心加速机制全部保留，加速效果零缩水**：
- 本地 RAM Cache（内存 0ms 热点命中）
- SSD/HDD 磁盘持久化缓存
- 动态 API 独立长连接池（省去 TCP+TLS 重复握手延迟）
- 静态素材 HTTP/2 多路复用与 SingleFlight 请求合并

本版本主要调整代理行为边界和兼容性，不改变核心缓存与连接复用架构，**升级后绝不会减速**。
