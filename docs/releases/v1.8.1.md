# GBF Accelerator v1.8.1 发布说明 (Release Notes)

> **发布日期**：2026-09-19  
> **版本定位**：协商缓存 304 响应标头解耦热修复、解决跳更新卡死问题与 GUI 提示修正  
> **发布包**：
> - Windows：`GBF_Accelerator_v1.8.1_GUI.zip`
> - macOS：`GBF_Accelerator_v1.8.1_macOS_universal2.zip`

---

## 📥 下载与使用

### Windows 用户
1. 前往 Releases 下载 `GBF_Accelerator_v1.8.1_GUI.zip`，解压即用；
2. 旧版本升级只需替换 `GBF_Accelerator.exe`，原有 `cache` 缓存与 `config.json` 自动继承。

### macOS 用户
1. 前往 Releases 下载 `GBF_Accelerator_v1.8.1_macOS_universal2.zip`（Universal 2 双架构通用包）；
2. 解压并将 `GBF_Accelerator.app` 替换至系统的【应用程序】（Applications）文件夹；
3. 如遇 Gatekeeper 拦截，打开终端执行一次 `xattr -cr /Applications/GBF_Accelerator.app` 即可放行。

---

## 🛠️ 主要修复内容

### 1. 协商缓存 304 标头安全解耦与防崩溃 (Hotfix)
- **故障排查**：在 v1.8.0 修复“关闭浏览器强缓存配置时严格不注入标头”的逻辑后，代理底层静态素材 304 协商响应中因硬编码读取 `Cache-Control`，在未开启该功能（或老配置继承）时抛出 `KeyError: 'Cache-Control'`，导致连接被强制中断并在游戏更新时频繁卡死。
- **防御性重构**：新增 `_build_304_headers()` 构造器，对 RAM 缓存命中与磁盘缓存命中的 304 协商响应头进行解耦与安全取值，严格遵循 RFC 规范，彻底消除标头缺失时抛出异常的隐患。
- **回归测试覆盖**：新增 Test 76 自动化测试，全面覆盖关闭浏览器强缓存场景下的 RAM/Disk 协商缓存请求。

### 2. GUI 界面文案与提示优化
- **纠正误导性提示**：将性能设置中“启用浏览器强缓存与渲染留存”的文字由历史残留的“（...，默认关闭）”更新修正为“（仅对版本化静态资源注入 immutable，推荐开启）”，消除配置歧义。
