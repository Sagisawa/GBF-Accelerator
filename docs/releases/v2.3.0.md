# GBF Accelerator v2.3.0 发布说明 (Release Notes)

> **发布日期**：2026-09-29  
> **版本定位**：全局 RAM 激进缓存加速、实时日志多词高亮与 LibXposed 102 适配加固  
> **发布包**：
> - Windows：`GBF_Accelerator_v2.3.0_GUI.zip`
> - macOS：`GBF_Accelerator_v2.3.0_macOS_universal2.zip`
> - Android (Root / LSPosed 模块)：`GBF_Accelerator_v2.3.0_Xposed_arm64.apk`

v2.3.0 在现有 Go 原生架构基础上，进一步实现全局 RAM Boost 激进内存缓存与全量预热，优化实时日志多关键词高亮检索与 macOS 原生键位自适应，并针对 Android 客户端接入官方 LibXposed 102 拦截链与生命周期加固。

---

## 📥 下载与使用

### Windows 用户
1. 下载 `GBF_Accelerator_v2.3.0_GUI.zip`，解压即用；
2. **旧版本升级**：
   - **方式一（推荐，控制台一键更新）**：可在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - **方式二（手动替换）**：退出正在运行的旧版程序，直接使用压缩包内的 `GBF_Accelerator.exe` 覆盖替换原有文件即可；原有的 `cache` 缓存目录与 `config.json` 自动继承。

### macOS 用户
1. 下载 `GBF_Accelerator_v2.3.0_macOS_universal2.zip`（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 `GBF_Accelerator.app` 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. **解除安全拦截（首次运行必须）**：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动打开内嵌 Web 控制台。

### Android 用户
- **免 Root 用户**：
  1. 在 PC 端打开控制台，切换至【Android 浏览器修补】页面；
  2. 准备好官方原版 SkyLeap 安装包（或系统 WebView 浏览器 APK），拖入页面即可一键检测依赖并注入加速核心；
  3. 将生成的安装包传至手机安装（若手机连接电脑开启了 USB 调试，可直接点击控制台的【一键安装到手机】）；
  4. 安装后在手机上直接打开修补版浏览器即可使用，无需后台常驻。
- **已 Root / LSPosed 用户**：
  - 可直接下载下方附件中的 `GBF_Accelerator_v2.3.0_Xposed_arm64.apk` 安装并在 LSPosed 管理器中激活模块，勾选官方原版 SkyLeap 或 Via 浏览器即可直接打开使用，无需修改或重打包宿主 APK。

## 🚀 主要更新

### ⚡ 全局 RAM Boost 激进内存缓存与全量预热

针对追求极致加载速度、拥有充裕内存的桌面设备，引入全新 RAM Boost 内存缓存能力：

* **统一预算与全量预热**：支持为 RAM 缓存设定统一内存预算配额，并在程序启动或闲暇时一键执行全量预热，将热点素材常驻在超低延迟的内存中；
* **并发安全与生命周期隔离**：对 RAM Boost 激进策略的状态切换、并发读写与淘汰逻辑进行严密并发加固，隔离预算空间，防止无序扩张；
* **测试隔离保护**：通过密闭环境单元测试杜绝 RAM 测试对宿主机实际物理内存产生非预期压力。

### 📊 实时日志多词高亮与 macOS 原生键位自适应

进一步提升 Web 控制台排查定位与交互体验：

* **多关键词独立高亮匹配**：日志检索框支持以空格分割多个关键词（如 `quest json`），系统将分别独立高亮各关键词匹配项，直观凸显复合条件；
* **macOS 原生快捷键自适应**：日志搜索自适应 macOS 原生规范快捷键（`Cmd+G` 跳转下一项、`Cmd+Shift+G` 跳转上一项），并根据客户端操作系统动态显示按键图标（`⌘` 与 `F3`）；
* **快捷键冲突消除**：彻底修复浏览器原生 `Ctrl+F` / `Cmd+F` 与应用内日志搜索的事件捕获冲突。

### 📱 Android 客户端架构加固与官方 LibXposed 适配

对 Android 移动端及浏览器嵌入链路进行重要加固与升级：

* **官方 LibXposed 102 拦截链**：全面适配官方 LibXposed API 102 规范，移除旧版历史 api-stub，实现标准化钩子拦截链；
* **SkyLeap 宿主启动与生命周期安全**：通过 ActivityThread 彻底解耦 Context 引用获取，并在 Application 初始化阶段安全注册 Activity 生命周期回调，杜绝因过早初始化或 Context 为空引发的宿主崩溃；
* **无根证书直连 MITM 增强**：在 SkyLeap WebViewClient 中针对代理流量接入实现安全 SSL 旁路，免去手机端繁琐的根证书导入；
* **Patcher 相对路径锚定修复**：修复 Android Patcher 工具相对输出路径解析逻辑，确保产物严格生成在指定的 App 基目录下。

### 🛡️ 预取稳定性提升与反向克制

* **无效素材预取抑制**：自动识别上游返回 404 及 410 的无效素材，并进行指数退避与临时抑制，彻底杜绝无意义的循环请求风暴与日志刷屏；
* **业务语义绝对透明**：保持所有动态业务接口透明直传，POST/PUT/DELETE 状态变更请求绝对零重试；严禁任何试图伪装成浏览器或反检测的过度工程。
