# GBF Accelerator v1.8.0 发布说明 (Release Notes)

> **发布日期**：2026-09-18  
> **版本定位**：macOS 原生平台支持、历史缓存安全轮转、Windows 代理冲突检测与跨平台更新适配  
> **发布包**：
> - Windows：`GBF_Accelerator_v1.8.0_GUI.zip`
> - macOS：`GBF_Accelerator_v1.8.0_macOS_universal2.zip`

---

## 📥 下载与使用

### Windows 用户
1. 下载 `GBF_Accelerator_v1.8.0_GUI.zip`，解压即用；
2. 旧版本升级直接替换 `GBF_Accelerator.exe` 即可，原有 `cache` 目录与 `config.json` 自动继承，无需重新配置。

### macOS 用户
1. 下载 `GBF_Accelerator_v1.8.0_macOS_universal2.zip`（Universal 2 双架构，原生支持 Intel 与 Apple Silicon Macs）；
2. 解压后将 `GBF_Accelerator.app` 拖入系统的【应用程序】（Applications）文件夹；
3. **解除安全拦截（首次运行必须）**：  
   由于开源软件未购买商业开发者证书，首次运行会被系统 Gatekeeper 拦截。请打开 Mac 自带的【终端】执行以下命令放行：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
   *(或在系统拦截弹窗后，前往【系统设置】->【隐私与安全性】底部点击【仍要打开】)*；
4. 启动后程序常驻顶部 Menu Bar 菜单栏，首次启动将自动引导完成钥匙串根证书信任与系统 PAC 代理配置。

## 🌟 主要更新内容

### 1. macOS 原生平台支持
- **原生菜单栏常驻**：基于 Cocoa/AppKit 构建 macOS 状态栏图标（Menu Bar item），支持一键启停、代理模式切换、PAC 地址复制与配置重载。
- **钥匙串证书自动信任**：首次启动自动检测自签 Root CA 并通过 `security` 写入登录钥匙串完成信任；退出时支持干净注销。
- **networksetup PAC 自动配置**：集成 `networksetup` 自动写入当前活动网卡的 PAC 代理配置，退出程序时自动复原，不残留失效代理。
- **LaunchAgents 开机自启**：支持在 macOS 下自动生成并注册 `~/Library/LaunchAgents` plist 配置。
- **双平台界面隔离**：macOS 专用自适应 Scrollable Canvas 仅在 Darwin 平台初始化，Windows 平台 100% 保持原生自适应紧凑卡片布局，杜绝跨平台 GUI 回归。

### 2. 历史版本缓存安全瘦身与轮转
- **跨版本素材目录归档与轮转**：游戏素材版本更迭时，对长期未命中的旧版本素材目录提供安全扫描与清理机制，有效控制磁盘膨胀。
- **完整性防护**：清理范围严格限制在静态缓存内，前台活动素材与当前活跃版本 100% 保持完整。

### 3. Windows 系统代理冲突检测与提醒
- **外部代理抢占检测**：启动与运行中检测系统代理配置；若被 Clash / v2rayN 等外部代理工具覆盖或修改，弹出温和提示并支持一键恢复。
- **防断网自愈保护**：在外部工具意外退出或注册表键值被改动时提供诊断信息，避免出现浏览器断网。

### 4. 自动更新器跨平台感知与 Universal 2 优先匹配
- **跨平台资源过滤**：客户端检查更新时自动识别当前操作系统，Windows 客户端自动过滤 macOS 压缩包，macOS 客户端自动过滤 Windows 安装包。
- **Universal 2 优先策略**：macOS 客户端检查新版本时，优先匹配 `universal2` 双架构通用安装包；若不存在则平滑回退至常规 macOS 安装包。

### 5. 更多改进与修复
- **Linux / 命令行模式支持**：新增无 GUI 模式与自动化证书安装脚本（详见 `docs/MAC_LINUX_NOGUI.md`）；
- **缓存配置修复**：修复当在配置中手动关闭 `enable_browser_cache` 时部分头未完全生效的问题；
- **接口重试精细化**：进一步收敛网络断连重试范围至严格只读幂等接口，写请求保持绝对 0 重试。
