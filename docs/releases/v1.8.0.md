# GBF Accelerator v1.8.0 发布说明 (Release Notes)

> **发布日期**：2026-09-18  
> **版本定位**：macOS 原生平台适配、历史缓存安全轮转、Windows 代理冲突检测与更新器 Universal 2 优先匹配  
> **发布包**：
> - Windows：`GBF_Accelerator_v1.8.0_GUI.zip`
> - macOS：`GBF_Accelerator_v1.8.0_macOS_universal2.zip`

---

## 版本概述

v1.8.0 引入了针对 macOS 平台的原生适配，支持通过原生状态栏图标、系统钥匙串 Root CA 证书自动信任、`networksetup` PAC 自动分流以及 LaunchAgents 开机自启动在 macOS 环境开箱即用，并提供面向 Intel 与 Apple Silicon 的 Universal 2 通用二进制发布包。同时，针对多版本共存场景引入了安全的历史缓存轮转机制，新增了 Windows 系统代理冲突检测与恢复，并优化了客户端自动更新层的跨平台与 Universal 2 资源匹配逻辑。

---

## 主要更新内容

### 1. macOS 原生平台支持
- **原生状态栏图标与菜单**：基于 Cocoa/AppKit（通过 PyObjC 条件依赖）构建 macOS 状态栏图标（Menu Bar item），支持启动/停止控制、代理模式切换、PAC 地址复制与配置热重载。
- **Keychain 证书自动信任**：macOS 首次启动自动检测自签 Root CA 并调用 `security add-trusted-cert` 写入登录钥匙串；退出或卸载时支持安全注销。
- **networksetup PAC 自动配置**：集成 `networksetup` 自动设置指定网卡的 PAC 自动代理 URL，并在程序退出时自动复原。
- **LaunchAgents 开机自启动**：支持为 macOS 生成并注册 `~/Library/LaunchAgents` plist 自启动配置。
- **Universal 2 双架构通用包**：提供面向 Intel (x86_64) 与 Apple Silicon (arm64) 的通用架构 `.app` 独立发布包（`GBF_Accelerator_v1.8.0_macOS_universal2.zip`）。
- **平台隔离防护**：macOS 专用自适应 Scrollable Canvas 仅在 `darwin` 平台启用，完全保留 Windows 原生几何布局（`winfo_reqheight` / 固定尺寸），避免跨平台 GUI 回归。

### 2. 历史版本缓存安全瘦身与轮转
- **跨版本素材目录归档与轮转**：游戏素材版本轮转时，对长期未命中的旧版本目录提供安全扫描与瘦身清理机制。
- **缓存完整性保障**：清理仅针对纯静态缓存，严格保持前台活动缓存与当前活跃版本的零破坏。

### 3. Windows 系统代理冲突检测与通知
- **冲突检测机制**：启动时检测 Windows 系统代理配置；若检测到被其他代理软件抢占或意外修改，弹出温和提示并支持一键恢复。
- **防覆盖保护**：在非正常退出或外部工具篡改注册表代理键值时提供诊断提示，保障代理通道正常。

### 4. 自动更新器平台感知与 Universal 2 优先匹配
- **跨平台资源过滤**：客户端检查更新时自动感知当前操作系统，Windows 客户端自动过滤 macOS 安装包，macOS 客户端自动过滤 Windows 安装包。
- **Universal 2 优先策略**：macOS 客户端匹配新版本资源时，优先匹配 `universal2` 双架构通用安装包；若不存在则平滑回退至常规 macOS 安装包。

## 升级指引

### Windows 用户
1. 从 Release 页面下载 `GBF_Accelerator_v1.8.0_GUI.zip`；
2. 解压并将 `GBF_Accelerator.exe` 替换原有文件；
3. 原有 `cache` 缓存目录与 `config.json` 配置自动继承，无需重新配置。

### macOS 用户
1. 从 Release 页面下载 `GBF_Accelerator_v1.8.0_macOS_universal2.zip`；
2. 解压得到 `GBF Accelerator.app`，将其拖入“应用程序”（Applications）文件夹；
3. 首次启动将自动引导完成 Root CA 证书安装与 PAC 系统代理配置。
