# GBF Accelerator v2.6.0 发布说明 (Release Notes)

> 发布日期：2026-11-22  
> 版本定位：下游HTTP/2多路复用与ECDSA加速、Web控制台流体玻璃重构与移动端抽屉 (Downstream HTTP/2 Multiplexing, Liquid Glass UI & Mobile Responsive Drawer)

> - Windows：GBF_Accelerator_v2.6.0_GUI.zip
> - macOS：GBF_Accelerator_v2.6.0_macOS_universal2.zip
> - Android (Root / LSPosed 模块)：GBF_Accelerator_v2.6.0_Xposed_arm64.apk

## 📥 下载与使用

### Windows 用户
1. 下载 GBF_Accelerator_v2.6.0_GUI.zip，解压即用；
2. 旧版本升级：
   - 方式一（推荐，控制台一键更新）：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - 方式二（手动替换）：退出正在运行的旧版程序，直接使用压缩包内的 GBF_Accelerator.exe 覆盖替换原有文件即可；原有的 cache 缓存目录与 config.json 自动继承。

### macOS 用户
1. 下载 GBF_Accelerator_v2.6.0_macOS_universal2.zip（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 GBF_Accelerator.app 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. 解除安全拦截（首次运行必须）：  
   打开终端执行以下命令清除系统隔离属性：
   xattr -cr /Applications/GBF_Accelerator.app
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台。

### Android 用户
- 免 Root 用户：在 Web 控制台的「Android 浏览器修补」页面中，拖入任意官方版本 SkyLeap APK，工具链将全自动完成解包、嵌入内置加速核心并一键签名；
- Root 用户模块更新：已刷入 KernelSU、APatch 或 Magisk 的设备，直接在管理器中安装更新 GBF_Accelerator_v2.6.0_Xposed_arm64.apk 并勾选目标浏览器后重启作用域即可。

> 网络环境与 ACGPower 说明：
> - 手机端内嵌核心默认以直连模式（direct_mode=true）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - 暂不支持安卓版 ACGPower (acgp)：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 tun2socks 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> 多浏览器切换注意事项（Android 进程冻结机制）：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🌐 核心功能与更新

### 1. 下游 HTTP/2 多路复用与 ECDSA 证书加速
- 现代协议栈支持：本地数据平面（8124 端口）支持 TLS ALPN 协商 HTTP/2，客户端单 TCP 链路上并发复用多个素材请求，消除并发素材下载阻塞与连接抖动；
- 高效 ECDSA P-256 叶子证书：根证书颁发动态叶子证书时优先采用 ECDSA P-256 算法，握手计算能耗降低 70% 以上，显著提升移动端冷启动连接速度；
- 全链路会话复用与 DNS 缓存：上游代理客户端与直连链路启用 TLS 会话缓存复用与带 TTL 的内存 DNS 解析池，削减跨海请求往返开销；
- 独立 CDN 上游通道：支持为 Akamai 静态素材节点独立配置 asset_upstream_proxy。

### 2. Web 控制台流体玻璃（Liquid Glass）视觉重构与移动端响应式抽屉
- 全新视觉体系：采用同心圆角、浅色/深色双主题流线质感、InfoTip 浮层气泡与沉浸式毛玻璃卡片排版；
- 悬浮可折叠侧边栏：PC 桌面端采用独立悬浮式导航，支持一键平滑收起/展开，并提供完整的键盘快捷键与主题记忆；
- 移动端 100% 舒展与抽屉导航：小屏模式下自动隐藏常驻侧栏，将全部可用宽度归还中央控制台，彻底根除文字挤压与折行问题；顶部集成滑动抽屉（MobileNavDrawer），全量功能无缝触达；
- 实时态势抬头显示（HUD）：请求命中、下载与 API 转发三列指标自适应排版，杜绝标题截断。

### 3. macOS 标准缓存目录平滑迁移与安全治理
- 标准数据目录适配：支持将缓存目录一键迁移至 macOS 官方推荐的标准路径（~/Library/Application Support/GBF-Accelerator/cache），彻底避免系统权限拦截弹窗；
- 迁移事务安全与冲突检测：内置源目录与目标目录校验、安全锁防篡改以及失败自动回滚机制。

### 4. Android 浏览器修补面板升级与合规保障
- 全内置修补流水线重构：Android 修补面板全面升级为分步流水线，环境依赖自动识别与一键下载；
- 合规声明与运行须知强化：使用须知明确注明针对 TUN 代理与 Android cgroup v2 进程冻结机制的适配说明，杜绝非预期断连。

### 5. 紧凑元数据索引（meta.idx）与预取流控
- 紧凑二进制元数据索引：本地缓存新增 meta.idx 极速落盘与加载机制，启动预热耗时大幅降低；
- 预取调度限速削峰：预取引擎引入 3-worker 共享 Pacer 调度器与 15~35ms 随机抖动，主动避让前台请求，减轻网络并发压力。

## 🛡️ 稳定性与透明性

- 业务语义绝对透明：所有非静态请求（/rest/、/quest/、/party/ 等）均通过专用连接池透明直通 Cygames，官方心跳与错误上报 100% 穿透，严禁任何业务数据改写或本地伪造；
- 非幂等写操作坚决零重发：技能施放、战斗操作、体力消耗等非幂等写操作严格受控，应用层最大重试次数为 1，底层连接池严格隔离自动重放，杜绝重复触发；
- 双平面拓扑与权限隔离：数据面代理端口（8124）支持局域网设备接入，控制面端口（8125）永远仅绑定 127.0.0.1 环回地址，外部网络绝对不可访问管理端点；
- 静态素材零指纹与防篡改：缓存素材严格还原上游 Akamai CDN 原始字节流，响应头零指纹污染，严禁向客户端注入任何自定义代理标头。
