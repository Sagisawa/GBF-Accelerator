# GBF Accelerator v2.1.0 发布说明 (Release Notes)

> **发布日期**：2026-09-22  
> **版本定位**：一键自动更新与自动重启、备用上游自动故障转移、Windows Root CA 证书引导与安装流程加固  
> **发布包**：
> - Windows：`GBF_Accelerator_v2.1.0_GUI.zip`
> - macOS：`GBF_Accelerator_v2.1.0_macOS_universal2.zip`

---

## 📥 下载与使用

### Windows 用户
1. 下载 `GBF_Accelerator_v2.1.0_GUI.zip`，解压即用；
2. **旧版本升级**：
   - **方式一（推荐，控制台一键更新）**：在旧版（v2.0.0+）控制台点击版本号或更新提示，直接点击【一键下载新版安装包】并在校验完成后点击【立即更新并重启】；
   - **方式二（手动替换）**：退出旧版程序后直接替换 `GBF_Accelerator.exe` 即可，原有的 `cache` 缓存目录与 `config.json` 自动平滑继承，无需重新配置。

### macOS 用户
1. 下载 `GBF_Accelerator_v2.1.0_macOS_universal2.zip`（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 `GBF_Accelerator.app` 拖入系统的【应用程序】（Applications）文件夹覆盖旧版；
3. **解除安全拦截（首次运行必须）**：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动打开内嵌 Web 控制台，首次运行若尚未安装根证书将自动引导完成钥匙串根证书信任与分流设置。

## 🌟 主要更新内容

### 1. 一键自动更新与平滑重启 (Self-Update & Seamless Restart)
- **官方 Release 双重校验**：控制台支持直接检查官方 GitHub Releases 并下载与当前平台匹配的正式更新包；内置 SHA-256 哈希指纹校验与压缩包归档结构完整性校验，杜绝因网络丢包或中间劫持导致的损坏包写入。
- **平滑自更新助手**：下载并通过校验后，可一键触发独立更新助手进行文件替换并自动重启主程序；控制台同步提供实时下载进度、取消任务、一键打开下载目录手动解压等全流程支持。
- **并发与路径安全防护**：更新任务包含全局互斥锁防重入、临时文件安全清理、路径越界防护及失败自动回滚逻辑。

### 2. 备用上游代理与自动故障转移 (Upstream Failover & Auto Recovery)
- **高可用双上游拓扑**：在现有主上游代理基础上，新增可选的备用上游代理配置（支持 HTTP / HTTPS / SOCKS5）。
- **硬故障即时切换**：当主上游遭遇 TCP 建连拒绝、超时断开等不可达故障时，代理引擎即时转移至备用上游，保障游戏会话连接不中断。
- **多维健康监测与软故障判定**：支持配置连续失败次数与延迟容忍阈值；当主上游持续出现严重延迟或丢包时安全触发故障转移。
- **自动探测回切机制**：在设定的冷却周期后，看门狗后台异步健康探测主上游可用性，确认恢复后平滑回切至主上游。
- **零干扰合规设计**：该功能默认关闭，不影响既有单上游使用习惯；直连模式下自动屏蔽，严格遵循业务透明与零侵入规范。

### 3. Windows Root CA 证书流程加固与首启引导
- **首次启动智能引导**：启动时智能检测当前操作系统根证书存储，若尚未信任本机 Root CA，控制台自动弹出安装引导，降低新手配置门槛。
- **恢复 Windows 原生确认对话框**：根证书安装恢复 Windows 原生系统安全确认机制，由系统弹出证书指纹与信任确认，确保流程可审计且合规。
- **修复注销后的重复安装行为**：改用系统证书存储接口执行精确注销，避免旧证书残留状态导致后续重新安装时跳过系统安全确认。
- **详细故障诊断信息**：若证书安装过程遇到系统策略或权限异常，完整保留 certutil 返回代码与错误信息并记入日志，同时在界面展示 Root CA SHA-1、SHA-256 与证书存储位置。

### 4. 稳定性、测试与发布工程加固
- **故障转移看门狗回归测试**：新增针对备用上游网络抖动、并发切换、看门狗探针竞争与恢复机制的完整自动化回归测试。
- **自更新端到端验证**：补齐更新包 SHA-256 校验、解压校验、目录逃逸防御与进程自杀重启模拟测试。
- **前端工具链集成测试**：新增 `vitest` 测试框架，覆盖证书引导与平台判定等前端辅助函数测试。
