# GBF Accelerator v2.5.0 发布说明 (Release Notes)

> 发布日期：2026-10-18  
> 版本定位：磁盘素材分类明细扫描与清理、Android太郎伴生支持及传输安全加固  
> 发布包：
> - Windows：GBF_Accelerator_v2.5.0_GUI.zip
> - macOS：GBF_Accelerator_v2.5.0_macOS_universal2.zip
> - Android (Root / LSPosed 模块)：GBF_Accelerator_v2.5.0_Xposed_arm64.apk

v2.5.0 是一次聚焦于磁盘素材资产可视化治理、移动端伴生浏览器兼容与核心网络传输安全加固的重要版本。

长期运行后本地缓存体积往往达到数十 GB，此前一键清空会导致全量素材重新下载；本版本正式引入磁盘缓存分类明细扫描与选择性清理能力，支持直观查看音频、立绘、战斗、剧情等各大分类的体积占用并实施细粒度清理；Android 免 Root 补丁机新增对“太郎”（Tarou）专用 WebView 伴生浏览器的识别与一键修补支持；底层网络引擎全面加固非幂等写请求的底层防重放机制与 Range / HEAD 语义隔离；控制台更新弹窗新增核心关注亮点呈现；此外补充了 DMM 平台域名的 PAC 与 SwitchyOmega 规则。

---

## 📥 下载与使用

### Windows 用户
1. 下载 GBF_Accelerator_v2.5.0_GUI.zip，解压即用；
2. 旧版本升级：
   - 方式一（推荐，控制台一键更新）：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - 方式二（手动替换）：退出正在运行的旧版程序，直接使用压缩包内的 GBF_Accelerator.exe 覆盖替换原有文件即可；原有的 cache 缓存目录与 config.json 自动继承。

### macOS 用户
1. 下载 GBF_Accelerator_v2.5.0_macOS_universal2.zip（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 GBF_Accelerator.app 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. 解除安全拦截（首次运行必须）：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台。

### Android 用户
- 免 Root 用户：
  1. 在 PC 端打开控制台，切换至【Android 浏览器修补】页面；
  2. 支持直接拖入官方原版、已修补安装包或检测到的已安装伴生浏览器（SkyLeap / Via / 太郎）；
  3. 点击制作后自动还原未注入核心的原版并注入最新版加速引擎；
  4. 生成安装包后传至手机安装（或通过 USB 调试【一键安装到手机】）即可使用。
- 已 Root / LSPosed 用户：
  - 可直接下载下方附件中的 GBF_Accelerator_v2.5.0_Xposed_arm64.apk 安装并在 LSPosed 管理器中激活模块，勾选官方原版 SkyLeap、Via 或太郎浏览器即可直接打开使用，无需修改或重打包宿主 APK。

> 网络环境与 ACGPower 说明：
> - 手机端内嵌核心默认以直连模式（direct_mode=true）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - 暂不支持安卓版 ACGPower (acgp)：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 tun2socks 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> 多浏览器切换注意事项（Android 进程冻结机制）：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🛠️ 核心更新特性详解

### 1. 磁盘素材分类明细扫描与细粒度清理
- 资产类型精细化聚合分析：扫描引擎支持将本地海量缓存文件按照游戏实际业务类型精准聚合归类，涵盖音频音效（sound）、主页与场景立绘（mypage/scene）、战斗动画与特效（battle）、任务副本素材（quest）以及通用脚本与UI等；
- 细粒度选择性清理：控制台支持直观查看各分类文件数量与磁盘占用，允许按分类单项清理已过时或低频素材，告别传统一键全清导致全量素材重新跨海下载的痛点；
- 后台低开销异步扫描：分类扫描过程采用分批并发与内存保护机制，不阻塞前台游戏代理与素材交付。

### 2. Android 伴生浏览器扩展：原生支持“太郎” (Tarou) WebView
- 伴生应用自动识别：Android 修补管线新增对已安装的“太郎”（Tarou）专用 WebView 浏览器的探测与表面化呈现；
- 免 Root 一键修补管线：支持拖入或自动识别 Tarou APK 并完成系统证书信任与代理重定向配置注入，为偏好使用专精浏览器的玩家提供一致的零门槛加速体验。

### 3. 核心传输与防重放约束强化
- 非幂等写请求传输层绝对零重发：严格隔离底层连接池在遭遇连接断开或复用异常时的自动重试行为，确保所有战斗指令、技能施放、抽卡及体力消耗等写操作最多仅尝试 1 次，彻底杜绝状态双发风险；
- Range 与 HEAD 协议语义透传：严密隔离 HTTP Range 分片请求与 HEAD 探测请求的缓存生命周期，确保分片流与头信息探测端到端透明直通上游；
- 缓存落地完整性与隔离兜底：强化静态素材入库校验与隔离沙盒逻辑，杜绝畸形与截断流污染本地存储。

### 4. 控制台交互体验与规则生态优化
- 更新弹窗关注焦点高亮：在客户端新版本发现弹窗中直观呈现当前版本最具价值的核心特性，方便玩家第一时间获知关键变更；
- DMM 域名规则生态补充：PAC 代理脚本与 SwitchyOmega 规则生成中完整收录 DMM 游戏入口与认证相关域名，保障 DMM 账号登录与链路跳转稳定。

## 🛡️ 稳定性与透明性

- 动态 API 业务语义零干预：非静态请求严格经由专用连接池透明转发，不修改任何业务 Header、Cookie 或响应状态码，保持端到端协议透明；
- 写请求坚决零重试：所有 POST / PUT / DELETE 写请求保持最多 1 次尝试，杜绝业务状态双发风险；
- 静态资源 Byte-for-Byte 原始字节保真：磁盘与内存中的素材流均严格保持 Akamai CDN 原始数据，绝无任何 DOM 注入或脚本篡改；
- 双平面拓扑安全边界：管理控制面始终且仅监听 Loopback（127.0.0.1），局域网模式仅开放代理数据面端口。
