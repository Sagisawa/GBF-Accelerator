# GBF Accelerator v2.5.0 发布说明 (Release Notes)

> 发布日期：2026-10-18  
> 版本定位：磁盘素材分类明细扫描与清理、Android太郎浏览器Patch页面识别支持、DMM域名规则生态补充、传输安全加固  
> 发布包：
> - Windows：GBF_Accelerator_v2.5.0_GUI.zip
> - macOS：GBF_Accelerator_v2.5.0_macOS_universal2.zip
> - Android (Root / LSPosed 模块)：GBF_Accelerator_v2.5.0_Xposed_arm64.apk

v2.5.0 是一次基于近两周全部开发提交的综合性大版本，全面覆盖磁盘素材资产可视化治理、核心网络引擎与并发调度加固、缓存落地保真自愈、双平面网络安全防御、Android 补丁体系升级及控制台交互优化。

长期运行后本地缓存往往达到数十 GB，此前一键清空会导致全量素材重新跨海下载；本版本正式引入磁盘缓存分类明细扫描与选择性清理能力，支持直观查看音频、立绘、战斗、剧情等各大分类的体积占用并实施细粒度清理；网络调度方面，彻底根治了后台预取在 SingleFlight 合并中因瞬断失败导致前台请求误报 502 的竞态缺陷，严密落实非幂等写请求传输层零重发、Range / HEAD 协议语义透传以及路由热路径零内存分配；安全方面，筑牢了 LAN 局域网针对控制端口与回环 IP 的恶意请求拦截防线，防范 DNS 重绑定攻击；Android 端不仅新增对“太郎”（Tarou）专用 WebView 伴生浏览器的识别与修补，更全面重构了外部执行超时控制、前置写权限探测与解包安全防护；此外同步提供了更新弹窗核心焦点高亮与 DMM 平台分流规则补全。

## 📥 下载与使用

### Windows 用户
1. 下载 GBF_Accelerator_v2.5.0_GUI.zip，解压即用；
2. 旧版本升级：
   - 方式一（推荐，控制台一键更新）：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - 方式二（手动替换）：退出正在运行的旧版程序，直接使用压缩包内的 GBF_Accelerator.exe 覆盖替换原有文件即可；原有的 cache 缓存目录与 config.json 自动继承。

### macOS 用户
1. 下载 GBF_Accelerator_v2.5.0_macOS_universal2.zip（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 GBF_Accelerator.app 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. 解除安全拦截（首次运行必须）：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台。

### Android 用户
- 免 Root 用户：
  1. 在 PC 端打开控制台，切换至【Android 浏览器修补】页面；
  2. 支持直接拖入官方原版、已修补安装包或检测到的已安装伴生浏览器（SkyLeap / Via / 太郎）；
  3. 点击制作后自动还原未注入核心的原版并注入最新版加速引擎；
  4. 生成安装包后传至手机安装（或通过 USB 调试【一键安装到手机】）即可使用。
- 已 Root / LSPosed 用户：
  - 可直接下载下方附件中的 GBF_Accelerator_v2.5.0_Xposed_arm64.apk 安装并在 LSPosed 管理器中激活模块，勾选官方原版 SkyLeap、Via 或太郎浏览器即可直接打开使用，无需修改或重打包宿主 APK。

> 网络环境与 ACGPower 说明：
> - 手机端内嵌核心默认以直连模式（direct_mode=true）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - 暂不支持安卓版 ACGPower (acgp)：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 tun2socks 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> 多浏览器切换注意事项（Android 进程冻结机制）：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🛠️ 核心更新特性详解

### 1. 磁盘素材分类明细扫描与细粒度清理
- 资产类型精细化聚合分析：扫描引擎支持将本地海量缓存文件按照游戏实际业务类型精准聚合归类，涵盖音频音效（sound）、主页与场景立绘（mypage/scene）、战斗动画与特效（battle）、任务副本素材（quest）以及通用脚本与UI等；
- 细粒度选择性清理：控制台支持直观查看各分类文件数量与磁盘占用，允许按分类单项清理已过时或低频素材，告别传统一键全清导致全量素材重新跨海下载的痛点；
- 后台低开销异步扫描：分类扫描过程采用分批并发与内存保护机制，不阻塞前台游戏代理与素材交付。

### 2. 核心网络引擎与并发调度加固
- SingleFlight 前后台竞态隔离与 502 穿透消除：修复了后台预取在与前台请求合并时，若后台任务遇网络波动失败而将 502 错误直接传递给前台跟随者的缺陷；优化后前台请求自动解耦并独立降级，避免前端出现非预期报错；
- 非幂等写请求传输层绝对零重发：严格隔离底层连接池在遭遇连接断开或复用异常时的自动重试行为，确保所有战斗指令、技能施放、抽卡及体力消耗等写操作最多仅尝试 1 次，彻底杜绝状态双发风险；
- Range 与 HEAD 协议语义透传：完整支持 HTTP Range 分片请求与 SectionReader 磁盘命中切片，严密隔离 HEAD 探测请求的缓存生命周期，确保头信息探测与分片流端到端透明直通上游；
- 路由热路径零内存分配：在主机名解析前增加冒号前置判定，消除 Go 标准库在纯域名场景下的 AddrError 堆内存逃逸，实现高频代理路由与预取检查热路径 0 B/op 分配；
- 请求目标大小写容错归一化：严格遵循 RFC 9112 规范，规范化绝对形式请求目标并剥离 userinfo，兼容大小写混合的主机请求头。

### 3. 缓存资产保真与安全隔离自愈
- 官方前端错误上报脚本误隔离修复：调整异常脚本隔离判定规则，精准放行包含 rest/error/js 的合法前端错误上报流，杜绝误判隔离；
- 历史版本轮转与 8 版本保留窗口对齐：调整过时版本缓存回退策略，与系统默认的 8 个游戏版本保留窗口严格对齐；
- 活动在途流式临时文件防护：在磁盘体检与瘦身审计中主动保护正在进行的流式写入临时文件，杜绝清理任务误删活跃下载流；
- RAM 预热大文件准入保护：优化内存缓存预热逻辑，自动跳过超出安全上限的超大单文件，防止系统启动时占用过高物理内存。

### 4. 局域网与双平面安全防御
- 局域网非法越权访问阻断：严厉拦截来自 LAN 局域网客户端试图通过普通 HTTP 或 CONNECT 代理隧道访问本机回环（Loopback）或管理控制端口（8125）的请求；
- DNS 重绑定二次解析防护：保证回环校验 IP 与实际网络拨号 IP 绝对一致，杜绝通过重绑定技术绕过安全边界；
- 全局配置写入锁统一与事务解耦：将系统代理开关、自启动配置及健康自愈等配置写入统一纳入事务锁管理，隔离网络重绑与运行时同步，杜绝配置覆盖与状态分裂。

### 5. Android 补丁机体系全面升级与“太郎”伴生支持
- 原生支持“太郎”（Tarou）WebView 伴生浏览器：Android 补丁管线新增对已安装的“太郎”专用游戏浏览器的探测与表面化呈现，支持免 Root 一键修补与分流注入；
- 环境初始化前置写权限探测：在安装 Android 构建环境前主动校验目标目录写权限，若处于 Program Files 等受限目录提前给出明确提权或更换目录指引，避免下载中断；
- 外部进程超时与任务取消机制：Java 与 LSPatch 外部调用全面引入上下文（Context）超时控制与主动取消机制，并在失败路径自动清理临时目录，杜绝无响应挂起；
- APK 上传防路径穿越与解包防炸弹：严格限制 APK 上传路径边界，限制解压文件数量、压缩比与最大字节数；在文件替换失败时具备原子备份回滚能力。

### 6. 控制台交互体验与生态规则优化
- 更新弹窗关注焦点高亮卡片：在客户端新版本发现弹窗中采用高对比度卡片直观呈现当前版本最具价值的核心特性，方便玩家第一时间获知关键变更；
- DMM 域名规则生态补充：PAC 代理脚本与 SwitchyOmega 规则生成中完整收录 DMM 游戏入口与认证相关域名，保障 DMM 账号登录与链路跳转稳定；
- macOS 根证书原子导入校验：优化 macOS Root CA 安装逻辑，验证新证书导入成功后再清理旧副本，防止用户取消授权导致信任链丢失。

## 🛡️ 稳定性与透明性

- 动态 API 业务语义零干预：非静态请求严格经由专用连接池透明转发，不修改任何业务 Header、Cookie 或响应状态码，保持端到端协议透明；
- 写请求坚决零重试：所有 POST / PUT / DELETE 写请求保持最多 1 次尝试，杜绝业务状态双发风险；
- 静态资源 Byte-for-Byte 原始字节保真：磁盘与内存中的素材流均严格保持 Akamai CDN 原始数据，绝无任何 DOM 注入或脚本篡改；
- 双平面拓扑安全边界：管理控制面始终且仅监听 Loopback（127.0.0.1），局域网模式仅开放代理数据面端口。
