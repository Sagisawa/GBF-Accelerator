# GBF Accelerator v1.7.2 发布说明 (Release Notes)

> **发布日期**：2026-09-16  
> **版本定位**：前台素材优先调度、预加载解耦与启动预热调优  
> **发布包**：GBF_Accelerator_v1.7.2_GUI.zip

---

## 版本概述

v1.7.2 主要针对进入副本或页面切换时的素材加载体验进行优化。本版本将静态素材的引用扫描从前台请求路径解耦至后台队列，并增加前台素材优先调度机制；同时将启动预热上限调整至 1500 项，缩短冷启动磁盘扫描耗时。

---

## 主要更新内容

### 1. 前台素材优先调度与 QoS 避让
- **前台请求优先保障**：增加前台活动素材计数。当浏览器正在拉取前台画面与战斗素材时，后台预加载任务主动暂停，优先保障前台请求带宽与连接资源。
- **调度平滑缓冲**：前台请求结束后增加短时冷却平滑，避免后台预加载立即恢复引发瞬时突发流量。

### 2. 预加载发现流水线异步解耦
- **引用扫描异步入队**：素材响应返回浏览器后，引用扫描逻辑异步投递至有界后台队列（容量 32），不阻塞当前响应管道。
- **磁盘状态检查卸载至线程池**：本地磁盘缓存命中状态检查移至后台工作线程池执行，减少慢速磁盘 I/O 对代理主事件循环的阻塞影响。
- **URL 规范化与背压控制**：统一域名小写并剥离动态 query 参数去重；当预加载队列满载时安全丢弃低优先级任务，防止任务堆积。

### 3. 启动预热项调整
- **预热上限调整（6000 → 1500 项）**：优先加载核心 JS/CSS、字体及高频 UI/图标，减少启动时非必要素材的扫描开销。
- **启动耗时优化**：启动阶段的磁盘扫描时间由 ~7.5 秒降低至 **1.5 ~ 2.5 秒**，缓解启动初期磁盘读写压力。
- 新增配置项 `"ram_warmup_max_items": 1500`，支持在 `config.json` 中按需微调。

### 4. 稳定性与状态规范化
- **端口绑定竞争修复 (#4)**：优化监听端口探测与绑定逻辑，减少端口残留时的等待重试开销。
- **隔离区匹配精准化**：收敛历史补丁识别特征，仅在异常语法上下文中判定，避免误判正常脚本。
- **协程状态操作收敛**：规范内部集合与计数器生命周期，统一在主事件循环中调度，符合 asyncio 规范。
- **可观测性增强**：磁盘缓存读取日志增加耗时显示（`CACHE-DISK (Xms)`），预加载队列日志增加扫描与磁盘检查耗时统计。
- **自动化测试扩充**：回归测试用例扩充至 69 项（100% 通过），覆盖有界背压、优先级时间轴及异常自愈。

## 性能与架构说明

- **多级缓存架构**：内存热点缓存（RAM Cache）+ 本地持久化缓存（SSD/HDD）。
- **双通道隔离**：动态 API 专属 HTTP/1.1 长连接池，静态素材 Akamai CDN 独立 HTTP/2 多路复用通道。
- **请求合并与防击穿**：SingleFlight 机制合并高并发同名静态素材请求，减少重复回源。

## 升级指引

3. 原有 `cache` 缓存目录与 `config.json` 配置自动继承，无需重新配置。
