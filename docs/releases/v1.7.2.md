# GBF Accelerator v1.7.2 发布说明 (Release Notes)

> **发布日期**：2026-09-16  
> **版本定位**：前台素材优先调度、预加载解耦防卡顿与启动预热调优  
> **发布包**：GBF_Accelerator_v1.7.2_GUI.zip

---

## 🌟 版本概述

GBF-Accelerator v1.7.2 重点解决了用户在“进入副本或页面冷启动时可能出现的瞬时卡顿/黑屏”现象。本版本彻底将静态素材的“发现扫描”与“前台请求管线”剥离解耦，并引入前台优先 QoS 协作避让机制，确保游戏前台的任何加载与操作均拥有绝对优先权。

同时，针对启动阶段的磁盘争用进行了精准调优，大幅缩短就绪时间，并在架构层面完成了严格的线程安全与生命周期收敛。

---

## 🚀 主要更新内容

### 1. 🛡️ 前台素材优先调度与 QoS 动态避让 (QoS Cooperative Scheduling)
- **前台优先绝对保障**：引入生命周期安全的前台资源计数器。当检测到浏览器正在发起前台画面与战斗素材拉取时，后台 Prefetch 立即主动刹车暂停，将 HTTP/2 多路复用连接与网络带宽 100% 留给前台。
- **平滑缓冲冷却**：前台请求结束后提供微秒级平滑冷却窗口，杜绝 Prefetch 立即恢复抢占造成的突发网络脉冲，保护前台首屏渲染与战斗动画流畅播放。

### 2. ⚡ 预加载深度解耦与事件循环防卡顿 (Event Loop Unstall)
- **前台 0 秒等待（纯异步投递）**：素材返回浏览器后立刻结束当前请求并继续读取浏览器后续指令，将素材引用扫描任务完全转移至容量限制为 32 的后台独立队列（前台耗时 < 0.001ms）。
- **磁盘检查全量卸载至工作线程池**：多达 120 次的本地磁盘命中状态查询（`stat()`）全部移入后台 Executor 线程池执行，彻底消除了慢速硬盘或 Windows Defender 实时防病毒扫描对代理主事件循环的阻塞隐患。
- **智能规范化去重与背压防护**：统一域名小写并剥离随机 query 参数，避免重复扫描；当后台队列满载时安全丢弃多余预加载任务，绝不拖累前台游戏正常请求。

### 3. 🚀 启动预热黄金调优 (RAM Warmup Optimization)
- **预热上限黄金调优（6000 → 1500 项）**：优先装载 100% 的核心 JS/CSS、字体及常用高频 UI/技能图标，剔除低频次要素材。
- **启动耗时缩短约 75%**：启动阶段的硬盘高负荷扫描时间从 ~7.5 秒大幅压减至 **1.5 ~ 2.5 秒**，双击打开软件后瞬间就绪，彻底杜绝开机初期与游戏争抢硬盘。
- 新增配置项 `"ram_warmup_max_items": 1500`，支持用户在 `config.json` 中按需微调。

### 4. 🛠️ 稳定性、生命周期规范化与可观测性
- **端口绑定竞争修复 (#4)**：重构监听端口绑定与探针检测逻辑，空闲端口快速直绑，解决 Windows 环境下残留实例造成的假超时弹窗。
- **隔离区匹配精准化**：收敛历史补丁隔离识别特征，严格限定在语法异常上下文中，杜绝正常脚本中合法代码的误判。
- **严格线程安全收敛**：规范内部状态集合的生命周期管理，彻底杜绝跨线程操作，100% 遵从 asyncio 协程安全规范。
- **细粒度耗时观测**：磁盘缓存读取日志增加耗时显示（`CACHE-DISK (Xms)`），预加载队列日志增加扫描与磁盘检查耗时统计（`PREFETCH-Q extract=Xms, check=Yms`）。
- **测试套件扩充**：自动化回归测试用例扩充至 **67 项（测试通过率 100%）**，全面覆盖有界背压、优先级时间轴与错误隔离。

## ⚡ 性能说明

**核心加速机制完整保留并持续进化**：
- 本地 RAM Cache（内存 0ms 热点命中）
- SSD/HDD 磁盘持久化缓存（2~3ms 极速固态响应）
- 动态 API 独立长连接池（省去 TCP+TLS 重复握手延迟）
- 静态素材 HTTP/2 多路复用与 SingleFlight 请求合并
- 智能削峰填谷平滑预取与前台避让调度

## 📦 升级指引

1. 从 Release 页面下载 `GBF_Accelerator_v1.7.2_GUI.zip`；
2. 解压并将 `GBF_Accelerator.exe` 替换原有文件即可；
3. 原有 `cache` 缓存目录与 `config.json` 配置自动平滑继承，无需重新配置或清空缓存。
