# GBF Accelerator v2.4.1 发布说明 (Release Notes)

> **发布日期**：2026-10-03  
> **版本定位**：一键系统健康体检与自动故障自愈、游戏数据驱动的素材智能预取、磁盘缓存命中整文件快速交付与 macOS 原生状态栏菜单适配  
> **发布包**：
> - Windows：`GBF_Accelerator_v2.4.1_GUI.zip`
> - macOS：`GBF_Accelerator_v2.4.1_macOS_universal2.zip`
> - Android (Root / LSPosed 模块)：`GBF_Accelerator_v2.4.1_Xposed_arm64.apk`

v2.4.1 是一次聚焦于运行稳定性、链路自愈与精细化资源调度的重要更新。

针对用户在日常使用中偶发的端口冲突、PAC 分流失效、根证书未受信任或防火墙拦截等系统环境问题，**本版本引入了一键系统健康体检与自动故障自愈管线**，可在控制台内跨 7 大核心维度自动化排查并安全批量修复，大幅降低环境配置与排错成本；同时引入**游戏数据驱动的素材智能预取**，在完全保持前台业务透明的前提下，提前发现关联静态素材，配合随机平滑调度削峰填谷；在底层传输与平台体验方面，重构了磁盘缓存命中的整文件快速交付路径，复用 512KB 流式缓冲池减少 GC 开销，并为 macOS 平台带来了完全遵循 Apple HIG 规范的原生状态栏菜单。

## 📥 下载与使用

### Windows 用户
1. 下载 `GBF_Accelerator_v2.4.1_GUI.zip`，解压即用；
2. **旧版本升级**：
   - **方式一（推荐，控制台一键更新）**：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - **方式二（手动替换）**：退出正在运行的旧版程序，直接使用压缩包内的 `GBF_Accelerator.exe` 覆盖替换原有文件即可；原有的 `cache` 缓存目录与 `config.json` 自动继承。

### macOS 用户
1. 下载 `GBF_Accelerator_v2.4.1_macOS_universal2.zip`（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 `GBF_Accelerator.app` 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. **解除安全拦截（首次运行必须）**：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台。

### Android 用户
- **免 Root 用户**：
  1. 在 PC 端打开控制台，切换至【Android 浏览器修补】页面；
  2. 支持直接拖入官方原版或已被旧版核心修补过的安装包，系统会自动识别并提示【重新修补 / 升级核心】；
  3. 点击制作后自动还原未注入核心的原版并注入最新版加速引擎；
  4. 生成安装包后传至手机安装（或通过 USB 调试【一键安装到手机】）即可使用。
- **已 Root / LSPosed 用户**：
  - 可直接下载下方附件中的 `GBF_Accelerator_v2.4.1_Xposed_arm64.apk` 安装并在 LSPosed 管理器中激活模块，勾选官方原版 SkyLeap 或 Via 浏览器即可直接打开使用，无需修改或重打包宿主 APK。

> **网络环境与 ACGPower 说明**：
> - 手机端内嵌核心默认以直连模式（`direct_mode=true`）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - **暂不支持安卓版 ACGPower (acgp)**：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 `tun2socks` 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> **多浏览器切换注意事项（Android 进程冻结机制）**：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），**在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭**，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🚀 核心更新

### 🩺 一键系统健康检查与全自动故障自愈 (Health Check & Repair Pipeline)

控制台新增系统健康状态诊断与自愈能力，帮助用户快速排查并一键修复常见网络与系统集成异常：

* **7 大核心维度深度体检**：  
  全面覆盖代理核心运行时（Core Process）、数据平面端口（Data Plane `:8124`）、控制平面端口（Control Plane `:8125`）、系统 PAC 代理指向有效性、本地自签 Root CA 证书信任状态、SSD 磁盘与 RAM 缓存读写健康、以及 Windows 本地防火墙入站端口规则；
* **一键自动安全修复**：  
  针对检测出的异常项目提供一键批量自愈操作；内置 Windows UAC 管理员提权引导与修改前配置快照回滚机制，修复过程透明可控，避免误改系统设置；
* **实时游戏连通性测速**：  
  集成游戏服务器专用连通性 Ping 测速探针，实时反映客户端到游戏 CDN 与动态 API 的网络链路延迟并给出健康评级。

---

### 🔮 游戏数据驱动的素材智能预取发现 (Game-Data Driven Dynamic Discovery)

升级后台预取引擎，实现从被动等待到主动预测的素材发现机制转变：

* **数据驱动动态发现**：  
  分析游戏核心业务响应中返回的动态关联信息，在零侵入前台 API 链路的前提下，智能提取后续即将访问的静态立绘、战斗素材与音频资源；
* **温和调度削峰填谷**：  
  发现的任务自动注入后台低优先级队列，保持 15~35ms 随机抖动平滑调度，严格控制对上游 CDN 的并发请求频率；
* **前台请求主动避让**：  
  当前台用户触发实时战斗、切页或静态素材拉取时，Prefetch 机制主动暂停让道，优先保障前台操作的最低延迟与带宽占用。

---

### ⚡ 磁盘缓存命中整文件交付与流式缓冲池复用

持续打磨本地缓存读取与网络流式交付性能：

* **整文件快速交付重构**：  
  针对已完成落盘校验的本地磁盘缓存，重构为直接整文件读取并交付响应，减少不必要的中间拷贝与分块调度开销，使磁盘缓存命中时的响应更加平稳迅速；
* **512KB 流式对象缓冲池复用**：  
  在 Stream-Through 流式传输热路径中引入 `streamBufferPool` 对象池复用机制，大幅减少大文件边下边传过程中的堆内存临时分配与 GC 压力；
* **流式耗时遥测**：  
  流式传输流程接入细粒度耗时遥测，便于在控制台与日志中量化观测各分块与首字节交付时间。

---

### 🍎 macOS 原生状态栏菜单适配 Apple HIG 规范

提升 macOS 桌面环境下的系统级整合体验：

* **符合 Apple HIG 规范的 Template 图标**：  
  状态栏图标采用原生矢量模板渲染，根据 macOS 系统外观设置（浅色 / 深色模式）自动自适应高反差反转；
* **原生上下文菜单交互**：  
  点击状态栏图标直接呼出原生菜单，支持快捷进入 Web 控制台、一键将根证书加入 macOS 系统钥匙串、平滑重启引擎及安全退出。

---

### 🛠️ 运行时生命周期泄露修复与界面响应式优化

* **Goroutine 生命周期收敛**：  
  修复 `PrefetchEngine` 在 `ProxyServer` 异常未启动或初始化中断路径下可能遗留后台工作协程的缺陷；
* **文件句柄生命周期加固**：  
  修复隔离损坏缓存时底层文件句柄未完全关闭的边界问题；
* **控制台响应式体验提升**：  
  将上游路由观测卡片扩充为 6 列自适应网格，彻底避免桌面端和移动端长 URL 挤压截断；响应式重构底部停靠栏与缓存目录控件。

---

## 🛡️ 稳定性与透明性

本版本继续严格遵循安全治理不变量：

* 动态游戏 API 原样透明转发，业务 Header 与 Body 零修改；
* POST / PUT / DELETE 状态变更请求绝对零重试；
* 静态资源缓存保持 Akamai CDN 原始字节流，无任何反检测伪装；
* 后台 Prefetch 主动避让前台请求；
* 日志与遥测采用有界、非阻塞方式，不阻塞代理数据面；
* Windows、macOS、Linux、Android 继续保持平台架构隔离。
