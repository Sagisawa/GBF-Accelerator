## 🎉 GBF Accelerator v1.1.0 正式版发布

碧蓝幻想（Granblue Fantasy）本地静态资源缓存与加速代理工具。

通过将游戏静态资源（立绘、音频、脚本、动画）本地化缓存至 SSD/内存，大幅降低跨海 CDN 网络延迟；同时透明联动 Clash / v2rayN 等上游代理，保证抽卡、多人战等核心 API 零篡改、原样稳定传输。

---

### ✨ 主要更新特性

#### 1. 🖥️ 图形化界面与系统托盘
- **原生界面**：采用 Windows 原生控件风格，高分屏（2K/4K/DPI 缩放）清晰适配，底部操作栏绝对防截断。
- **后台静默**：支持最小化至系统托盘，后台静默加速，低资源占用。
- **灵活配置**：
  - 支持自定义本地监听端口（默认 `8124`）。
  - 支持一键自动探测本地代理（Clash Verge、Clash、v2rayN）。
  - 支持自动检测并无缝复用已有 ACGPower 历史缓存。
- **系统 PAC 自动化**：支持一键开启 Windows 系统 PAC 自动分流，浏览器无需安装任何插件，开箱即玩；同时兼容 SwitchyOmega / ZeroOmega 等扩展配置。

#### 2. ⚡ 性能与资源自由调度
- **内存热点缓存 (RAM Cache)**：高频静态资源直接在内存中命中，0 磁盘 I/O 毫秒级极速直出。
- **浏览器强缓存与渲染留存**：智能注入 `immutable` 标识加速切屏，减少页面重绘。
- **缓存自动自愈**：自动检测并清除 0 字节损坏或残缺文件并重新拉取，杜绝黑屏死卡。

#### 3. 🛡️ 协议解析与核心 API 严格保护
- **全功能 HTTP 解析器**：完整支持 `Transfer-Encoding: chunked` 分块传输编码、64KB 头部上限、32MB 请求体保护与超时防护。
- **动态 API 100% 原样透传**：抽卡、编队、结算、`/socket/` 多人战等核心 API 严格保留原生 Cygames / Mobage 响应头与 CORS，绝不随意强行注入通配符，杜绝带凭证请求报错与战斗不同步风险。
- **自适应解压修复**：智能识别上游压缩传输与本地解压，杜绝客户端二次解压报错。

#### 4. 🔒 安全加固与生命周期透明化
- **根证书透明管理**：主界面直观展示本地自签名根证书的 **SHA-256 指纹**，支持 **一键注销/卸载根证书**，干净移除系统信任。
- **严格收敛分流规则**：PAC 与 SwitchyOmega 规则收敛限制为 `gbf.akamaized.net`，坚决不通配公共 `*.akamaized.net`，彻底隔离 Steam、苹果等其他国际应用流量。
- **上游 TLS 验证**：默认启用上游 TLS 证书校验 (`verify_upstream_tls: true`)。
- **防误杀端口保护**：仅在必要时清理加速器残留僵尸进程，绝不误杀系统或其他三方软件。
