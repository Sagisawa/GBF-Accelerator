## 🚀 快速上手与更新指南

### 1. Windows 用户指南
- 自动升级：通过 Web 控制台右上角更新检测直接点击一键升级，程序将自动下载并完成无缝替换；
- 手动更新：下载 GBF_Accelerator_v2.5.1_GUI.zip，解压后覆盖替换旧版目录中的 GBF_Accelerator.exe 即可；
- 语言切换：启动后点击 Web 控制台右上角的语言菜单，可在 简体中文、English、日本語 之间自由切换。

### 2. macOS 用户指南
- 解除隔离拦截：首次打开 GBF_Accelerator.app 时，若提示开发者未验证或文件损坏，在终端执行以下命令解除隔离属性：
  xattr -cr /Applications/GBF_Accelerator.app
- 菜单栏托盘：原生状态栏托盘已完整支持中、英、日三语动态跟随，可随时通过托盘菜单切换语言或查看运行状态。

### 3. Android 玩家指南
- 免 Root 浏览器修补：在 Web 控制台的「Android 浏览器修补」页面中，拖入任意官方版本 SkyLeap APK，工具链将全自动完成解包、嵌入内置加速核心并一键签名；
- Root 用户模块更新：已刷入 KernelSU、APatch 或 Magisk 的设备，直接在管理器中安装更新 GBF_Accelerator_v2.5.1_Xposed_arm64.apk 并勾选目标浏览器后重启作用域即可。

## 🌐 核心功能与重大更新

### 1. 全界面多语言支持与国际化架构
- Web 管理控制台完整支持中文、英文、日文三种语言，涵盖主仪表盘、分类缓存清理、RAM 常驻池、网络延迟测速、实时日志高亮、证书安装引导与分流配置等全部 16 个核心交互弹窗与抽屉面板；
- 语言设置支持在控制台右上角即时无缝切换，并持久化保存至本地系统配置；
- 桌面系统托盘菜单（Windows 任务栏通知区与 macOS 顶部菜单栏）全面支持中英日三语随语言配置联动；
- 端口 8124 移动端局域网引导页实现浏览器首选语言自动探测与手动无跳转切换。

### 2. 游戏与网络术语专业化润色与反借词重构
- 术语脱敏与合规化：彻底消除全项目文档、架构流程图与词典中易引起外挂与安全误解的直译词汇，统一规范为补丁制作（Patch）与模块嵌入（Embed）；
- 日文本地化地道重构：全面消除汉式日文直译（Calque），将静态素材统一规范为游戏行业标准的静的アセット（Static Asset），避免与游戏内强化突破素材产生歧义；将浏览器强缓存规范为ブラウザキャッシュ制御，长连接复用规范为 Keep-Alive，主界面规范为メイン画面，完整环境规范为ツールチェーン（Toolchain）；
- iOS 与 macOS 系统级词汇对齐：移动端证书引导文案与苹果官方系统描述文件安装提示横幅精确对齐。

### 3. 说明文档与多语言图库全量配套
- 独立三语使用说明：根目录与引擎内嵌资源同步推出 INSTRUCTIONS_EN.txt 与 INSTRUCTIONS_JA.txt，完整包含商业加速器进程改名技巧（chrome.exe / chrome.app）与主流代理共存指引；
- 独立多语言 README：新增 README.en.md 与 README.ja.md，配套全套最新高清预览图表，多语言文案与表格对齐无坏链；
- 分流指引精简：移除配置导入步骤中冗余的 PAC 复制行，聚焦直观的操作流程。

## 🛡️ 稳定性与透明性

- 业务语义绝对透明：所有非静态请求（/rest/、/quest/、/party/ 等）均通过专用连接池透明直通 Cygames，官方心跳与错误上报 100% 穿透，严禁任何业务数据改写或本地伪造；
- 非幂等写操作坚决零重发：技能施放、战斗操作、体力消耗等非幂等写操作严格受控，应用层最大重试次数为 1，底层连接池严格隔离自动重放，杜绝重复触发；
- 双平面拓扑与权限隔离：数据面代理端口（8124）支持局域网设备接入，控制面端口（8125）永远仅绑定 127.0.0.1 环回地址，外部网络绝对不可访问管理端点；
- 静态素材零指纹与防篡改：缓存素材严格还原上游 Akamai CDN 原始字节流，响应头零指纹污染，严禁向客户端注入任何自定义代理标头。
