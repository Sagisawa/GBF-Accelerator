## 📥 下载与使用

### Windows 用户
1. 下载 GBF_Accelerator_v2.5.1_GUI.zip，解压即用；
2. 旧版本升级：
   - 方式一（推荐，控制台一键更新）：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - 方式二（手动替换）：退出正在运行的旧版程序，直接使用压缩包内的 GBF_Accelerator.exe 覆盖替换原有文件即可；原有的 cache 缓存目录与 config.json 自动继承；
3. 语言切换：启动后点击 Web 控制台右上角语言菜单，可在 简体中文、English、日本語 之间自由切换。

### macOS 用户
1. 下载 GBF_Accelerator_v2.5.1_macOS_universal2.zip（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 GBF_Accelerator.app 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. 解除安全拦截（首次运行必须）：  
   打开终端执行以下命令清除系统隔离属性：
   xattr -cr /Applications/GBF_Accelerator.app
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台，菜单栏托盘随语言设置自动切换中、英、日三语。

### Android 用户
- 免 Root 用户：在 Web 控制台的「Android 浏览器修补」页面中，拖入任意官方版本 SkyLeap APK，工具链将全自动完成解包、嵌入内置加速核心并一键签名；
- Root 用户模块更新：已刷入 KernelSU、APatch 或 Magisk 的设备，直接在管理器中安装更新 GBF_Accelerator_v2.5.1_Xposed_arm64.apk 并勾选目标浏览器后重启作用域即可。

> 网络环境与 ACGPower 说明：
> - 手机端内嵌核心默认以直连模式（direct_mode=true）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - 暂不支持安卓版 ACGPower (acgp)：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 tun2socks 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> 多浏览器切换注意事项（Android 进程冻结机制）：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🌐 核心功能与更新

### 1. 全界面多语言支持
- 控制台多语言无缝切换：完整支持 简体中文、English、日本語，配置实时生效并持久化保存；
- 托盘与移动端引导联动：桌面系统托盘（Windows / macOS）与 8124 端口移动端引导页全面支持多语言自适应显示。

### 2. 术语专业化与合规重构
- 规范化中立叙事：消除敏感直译词汇，规范为补丁制作（Patch）与模块嵌入（Embed）；
- 系统文案精确对齐：移动端证书引导文案与 iOS 官方系统设置横幅精确匹配。

### 3. 多语言手册与指引精简
- 独立多语言说明书：推出配套的 INSTRUCTIONS_EN.txt 与 INSTRUCTIONS_JA.txt；
- 流程体验精简：新增独立多语言 README 与界面预览，移除配置导入方式一中冗余的 PAC 复制行。

## 🛡️ 稳定性与透明性

- 业务语义绝对透明：所有非静态请求（/rest/、/quest/、/party/ 等）均通过专用连接池透明直通 Cygames，官方心跳与错误上报 100% 穿透，严禁任何业务数据改写或本地伪造；
- 非幂等写操作坚决零重发：技能施放、战斗操作、体力消耗等非幂等写操作严格受控，应用层最大重试次数为 1，底层连接池严格隔离自动重放，杜绝重复触发；
- 双平面拓扑与权限隔离：数据面代理端口（8124）支持局域网设备接入，控制面端口（8125）永远仅绑定 127.0.0.1 环回地址，外部网络绝对不可访问管理端点；
- 静态素材零指纹与防篡改：缓存素材严格还原上游 Akamai CDN 原始字节流，响应头零指纹污染，严禁向客户端注入任何自定义代理标头。
