# GBF Accelerator v2.4.2 发布说明 (Release Notes)

> **发布日期**：2026-10-06  
> **版本定位**：跨格式图像素材容错校验与图裂修复、上游故障主备倒换系统级通知与桌面托盘集成、SmartProxy 分流规则同步  
> **发布包**：
> - Windows：`GBF_Accelerator_v2.4.2_GUI.zip`
> - macOS：`GBF_Accelerator_v2.4.2_macOS_universal2.zip`
> - Android (Root / LSPosed 模块)：`GBF_Accelerator_v2.4.2_Xposed_arm64.apk`

v2.4.2 是一次聚焦于静态素材渲染容错、链路状态感知与网络规则配置的稳定性更新。

针对近期活动（如转世3 / 异转律的小世界等）中出现的队伍空白位、战斗空角色位底图图裂问题，本版本经过上游现地探针排查，**重构了图像资产的魔数校验与格式嗅探逻辑**，支持合法图片格式魔数跨扩展名互认，彻底消除了官方素材编码错配引发的 502 Bad Gateway 阻断；同时**为上游主备代理自动故障转移新增了桌面系统级通知与托盘集成**，在主代理发生网络波动或切换时能够主动提示状态与原因，支持在控制台内一键开关；此外同步更新了 `SmartProxy_GBF.json` 规则配置备份与代理服务器命名规范。

## 📥 下载与使用

### Windows 用户
1. 下载 `GBF_Accelerator_v2.4.2_GUI.zip`，解压即用；
2. **旧版本升级**：
   - **方式一（推荐，控制台一键更新）**：在控制台版本卡片直接点击【一键下载新版安装包】，SHA-256 校验通过后点击【立即更新并重启】平滑升级；
   - **方式二（手动替换）**：退出正在运行的旧版程序，直接使用压缩包内的 `GBF_Accelerator.exe` 覆盖替换原有文件即可；原有的 `cache` 缓存目录与 `config.json` 自动继承。

### macOS 用户
1. 下载 `GBF_Accelerator_v2.4.2_macOS_universal2.zip`（Universal 2 双架构，原生兼容 Intel 与 Apple Silicon Macs）；
2. 解压后将 `GBF_Accelerator.app` 拖入系统的【应用程序】（Applications）文件夹覆盖；
3. **解除安全拦截（首次运行必须）**：  
   打开终端执行以下命令清除系统隔离属性：
   ```bash
   xattr -cr /Applications/GBF_Accelerator.app
   ```
4. 启动后程序自动常驻顶部系统状态栏并打开内嵌 Web 控制台。

### Android 用户
- **免 Root 用户**：
  1. 在 PC 端打开控制台，切换至【Android 浏览器修补】页面；
  2. 支持直接拖入官方原版或已被旧版核心修补过的安装包，系统会自动识别并提示【重新修补 / 升级核心】；
  3. 点击制作后自动还原未注入核心的原版并注入最新版加速引擎；
  4. 生成安装包后传至手机安装（或通过 USB 调试【一键安装到手机】）即可使用。
- **已 Root / LSPosed 用户**：
  - 可直接下载下方附件中的 `GBF_Accelerator_v2.4.2_Xposed_arm64.apk` 安装并在 LSPosed 管理器中激活模块，勾选官方原版 SkyLeap 或 Via 浏览器即可直接打开使用，无需修改或重打包宿主 APK。

> **网络环境与 ACGPower 说明**：
> - 手机端内嵌核心默认以直连模式（`direct_mode=true`）运行，配合主流基于 TUN 网卡的网络工具（如 Clash、v2rayNG、Sing-box、网易UU加速器、奇游、岛风go 等）均可正常使用；
> - **暂不支持安卓版 ACGPower (acgp)**：由于安卓端 ACGPower 并非标准 IP 隧道，而是通过 `tun2socks` 重定向到本地代理且每次启动随机分配动态端口，无法做透明直连转发。若在手机上使用 ACGPower，建议直接使用其官网提供的定制版 SkyLeap 客户端。
>
> **多浏览器切换注意事项（Android 进程冻结机制）**：  
> Android 系统后台管理机制（cgroup v2 freezer）会在应用退入后台后冻结挂起其所有子进程（包括内嵌的 Go 加速核心），且应用私有沙盒相互隔离。若您在同一设备上安装了多个适配浏览器（如 SkyLeap 与 Via），**在切换浏览器前，请务必在多任务界面中将前一个浏览器彻底上滑关闭**，避免后台被冻结的核心占用 8124 端口导致新浏览器请求未响应。

## 🛠️ 核心更新特性详解

### 1. 跨格式图像素材容错校验与图裂根治
- **现地根因排查**：分析发现，Cygames 官方在部分活动素材（如转世3空角色位 `base_character_empty.png`、地下城编队效果 `base_character_empty.png`、空战斗角色 `empty_arcarum3.png`）中，存在文件扩展名为 `.png`、上游响应头为 `image/png`，但实际文件体以 `\xff\xd8\xff\xe1` 开头（即真实编码为 JPEG EXIF 格式）的官方编码错配；
- **容错校验机制**：调整 `checkMagicBytes` 逻辑，在文件为图像扩展名时，优先比对扩展名原生魔数；若官方未按规范编码，只要二进制文件体符合任意合法图像格式（PNG / JPEG / WebP / GIF），均判定为有效素材予以正常缓存与透传交付，避免此前误拦截并返回 502 Bad Gateway 造成的图裂；
- **缓存安全与防线保留**：继续严格拦截并丢弃运营商劫持的 HTML 网页、502/503 纯文本报错以及 0 字节损坏文件，确保落盘与内存缓存的资产纯净性。

### 2. 上游主备故障倒换系统级通知与桌面托盘集成
- **原生状态感知**：当主代理出现网络故障、超时高延迟或连续连接失败并自动转移至备用代理时，系统自动触发原生桌面托盘气泡通知，告知用户切换状态与触发耗时；
- **双向恢复提示**：当主代理连通性恢复并自动切回主链路时，同步弹出恢复通知；
- **控制台开关可配**：新增 `upstream_failover_notification` 配置项，允许用户在控制台全局设置中按需开启或静音提醒。

### 3. SmartProxy 浏览器扩展规则配置同步
- **开箱即用规则导出**：主程序根目录提供 `SmartProxy_GBF.json` 规则文件，适配主流 Chromium / Firefox 浏览器；
- **分流规则与命名标准化**：规范化代理服务器标识，保障游戏 API 与素材加速规则精准命中。

## 🛡️ 稳定性与透明性

- **动态 API 业务语义零干预**：非静态请求严格经由专用连接池透明转发，不修改任何业务 Header、Cookie 或响应状态码，保持端到端协议透明；
- **写请求坚决零重试**：所有 POST / PUT / DELETE 写请求保持最多 1 次尝试，杜绝业务状态双发风险；
- **静态资源 Byte-for-Byte 原始字节保真**：磁盘与内存中的素材流均严格保持 Akamai CDN 原始数据，绝无任何 DOM 注入或脚本篡改；
- **双平面拓扑安全边界**：管理控制面始终且仅监听 Loopback（127.0.0.1），局域网模式仅开放代理数据面端口。
