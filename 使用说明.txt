=================================================================
   GBF 加速器（GBF Accelerator）使用说明与全流程指引
=================================================================

【写在前面：开源软件未签名与安全拦截说明】
-----------------------------------------------------------------
本项目为开源本地静态资源缓存与透明代理工具，完全免费且代码开源。
由于未采购商业代码签名证书，部分操作系统首次运行时可能会弹出安全警告：

• Windows 10/11 用户（SmartScreen 拦截）：
  首次双击 GBF_Accelerator.exe 时，若弹出【Windows 已保护你的电脑】或
  【Microsoft Defender SmartScreen 阻止了无法识别的应用启动】弹窗：
  1. 点击弹窗上的【更多信息】（More info）；
  2. 点击右下角出现的【仍要运行】（Run anyway）即可正常启动。
  （若被第三方杀毒软件拦截，请点击“信任并放行”或添加至白名单）。

• macOS 用户（Gatekeeper 拦截）：
  首次打开 GBF_Accelerator.app 时，若提示“无法验证开发者”或“已损坏”：
  1. 在【访达】（Finder）中找到该应用，按住 Control 键并鼠标右键点击，选择【打开】；
  2. 或打开系统【终端】（Terminal）执行以下命令解除系统隔离：
     xattr -cr /Applications/GBF_Accelerator.app

【快速上手：标准 4 步全流程】
=================================================================

第 1 步：准备上游代理（前置网络）
-----------------------------------------------------------------
1. 确保你的代理软件（Clash Verge / Clash / v2rayN / Surge 等）已开启并正常翻墙联网。
2. 本加速器作为“本地中继与缓存加速中间件”，默认会自动探测本机的上游代理端口：
   • Clash Verge 常见为 7897
   • 原版 Clash 常见为 7890
   • v2rayN 常见为 10809
   • 岛风 GO 默认为 8099（开启后可自动适配并支持自签证书）
   若同时开启了多个代理，可在控制台的“上游代理”下拉框中自由切换。
3. （可选）如果你拥有直连日本服务器的专线或不想走任何梯子，可在软件界面勾选【直连模式】。

第 2 步：启动本程序并安装 HTTPS 根证书（【必做】，只需首次操作一次）
-----------------------------------------------------------------
静态素材由 Akamai CDN 经由 HTTPS 传输，必须信任本机独立自签的根证书，否则浏览器会拦截素材并报错证书无效！

1. 启动本程序（Windows 双击 GBF_Accelerator.exe，macOS 打开 GBF_Accelerator.app）；
2. 程序启动后会自动打开 Web 管理控制台页面（默认地址 http://127.0.0.1:8125）；
3. 证书安装方式（二选一即可）：
   • 方式 A（推荐，界面一键）：在控制台界面顶部点击【一键安装根证书】（或“未安装信任”徽标），在系统弹出的安全警告窗口中点击【是】（Yes）确认信任即可！
   • 方式 B（脚本安装）：直接双击运行本程序根目录下的【install_ca.bat】（macOS 用户运行 ./install_ca.sh），按提示确认。

第 3 步：配置浏览器分流（推荐使用 ZeroOmega / SwitchyOmega 插件）
-----------------------------------------------------------------
分流的目的是让“仅 GBF 游戏流量与素材”经过加速器，其他网页正常直连或走梯子，互不干扰。

• 推荐方式（最省心、永不漏 CDN 分片、免手动维护）：
  1. 在 Chrome / Edge 浏览器中安装 ZeroOmega 或 SwitchyOmega 扩展；
  2. 打开插件设置 -> 点击左侧【新建情景模式】 -> 选择【PAC 情景模式】；
  3. PAC 网址填入：http://127.0.0.1:8124/proxy.pac，点击【立即更新】后点击左侧【应用选项】；
  4. 点击浏览器右上角插件图标，直接切换为该 PAC 情景模式即可！

• 备用方式 1（免插件，Windows 系统 PAC）：
  在控制台主界面直接勾选【自动配置 Windows 系统 PAC 代理】。
  【注意】：如果你浏览器安装了 SwitchyOmega，必须将插件图标切换到【[系统代理]】档位或暂时禁用插件，否则浏览器插件会强行覆盖系统代理导致失效！

• 备用方式 2（Clash TUN 虚拟网卡模式共存方案）：
  若电脑开启了 Clash TUN 模式接管虚拟网卡，TUN 会抢占系统 PAC 路由。此时推荐在 SmartProxy 插件中配置专属分流：添加 127.0.0.1:8124 代理目标，并将以下 7 条域名指向该代理：
  - granbluefantasy.jp
  - granbluefantasy.com
  - mbga.jp
  - mobage.jp
  - *granbluefantasy.akamaized.net
  - *gbf.akamaized.net
  - *granbluefantasy-steam.akamaized.net（Steam版）

第 4 步：进入游戏与加速生效确认
-----------------------------------------------------------------
1. 在浏览器中直接输入并打开官方游戏地址：
   https://game.granbluefantasy.jp
   【特别提醒】：请勿使用 SkyLeap 的 gbf.game.mbga.jp 地址游玩，该域名主要用于手机账号鉴权与跳转，不包含任何游戏静态素材，无法触发本地缓存加速。
2. 如何确认加速已正常生效：
   • 首次进入某个新场景或副本时，本地尚未缓存，素材需要经由网络首次下载；
   • 从第二次重复进入起，控制台顶部的【本地缓存命中】数字会快速跳动增加；
   • 此时立绘、音频与动效直接从你电脑的 RAM 内存（0ms）或 SSD 磁盘（1~3ms）瞬时交付，不再走跨海网络。

【移动端（手机 / iPad）局域网接入说明】
=================================================================
1. 确保手机与电脑连接在同一个 Wi-Fi 局域网下；
2. 在电脑端控制台开启【允许局域网连接】（需要放行 Windows 防火墙时，点击界面的一键防火墙适配）；
3. 手机浏览器访问控制台显示的局域网地址（例如 http://192.168.x.x:8124/），根据移动端向导页完成证书安装与 Wi-Fi 代理配置：
   • iOS 必做：下载描述文件安装后，必须前往【设置】->【通用】->【关于本机】-> 底部【证书信任设置】，打开“GBF Local Accelerator Root CA”的完全信任开关！
   • Wi-Fi 代理：选择【自动】，URL 填入 http://<电脑IP>:8124/proxy.pac。

【常见问题与技术说明】
=================================================================
1. 为什么抽卡、编队、战斗结算的延迟没有感觉明显变快？
   - 本加速器是【静态资源缓存加速器】，专门解决立绘、背景、技能动画、音频等 GBF 庞大静态素材加载卡顿、黑屏的问题。
   - 游戏的动态 API 请求（攻击、技能、抽卡、多人战）遵循业务语义绝对透明原则，端到端原样转发至上游代理，不干预、不伪造任何游戏数据，因此动态交互延迟完全取决于你的梯子节点网络质量。
2. 缓存占用磁盘过多怎么办？
   - 控制台提供了【历史版本安全瘦身】功能，会自动清理已被游戏更新废弃的历史旧版本代码碎片，立绘与音频等高价值大素材 100% 完好保留。
3. 卸载或不再使用时如何清理证书？
   - 控制台支持【一键注销证书】，点击即可从系统根证书库中彻底安全移除。
